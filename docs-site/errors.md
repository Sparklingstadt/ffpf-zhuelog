# エラー

## 形式

エラーの応答は、ステータスコードにかかわらず常に次の形です。

```json
{
  "error": {
    "code": "not_found",
    "message": "見つかりません。"
  }
}
```

| フィールド | 内容                                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| `code`     | 機械が判定するための固定の文字列。アプリの分岐にはこちらを使います                                    |
| `message`  | 利用者にそのまま見せられる日本語。文言は Web と同じにしてあり、変わることがあるので分岐には使いません |

- `message` に内部のエラーの詳細が入ることはありません。原因はサーバーのログにだけ出ます。
- エラーの応答にも `Cache-Control: no-store` が付きます。
- panic はミドルウェアで捕まえて `500 internal` にします。

## コードの一覧

| HTTP | code                       | 主な `message`                                             | 状況                                                                                                                                                                                                            |
| ---- | -------------------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 400  | `invalid_request`          | 「リクエストが不正です。」                                 | JSON が不正、未知のフィールド、`null`、検証エラー、クエリ（`limit`・`cursor`・`user`）が不正、`?user=` を受け付けないルートに付けた                                                                             |
| 400  | `invalid_request`          | 「パスワードは12〜128文字にしてください。」ほか            | パスワードの変更・会員の管理・CSV で、項目ごとの文言を返す検証エラー                                                                                                                                            |
| 400  | `password_mismatch`        | 「確認用のパスワードが一致しません。」                     | パスワードの変更で、確認用が一致しない                                                                                                                                                                          |
| 400  | `invalid_current_password` | 「現在のパスワードが違うか、一時的にロックされています。」 | パスワードの変更で、今のパスワードが違う・試行が多すぎる（アカウントごとに 15 分で 5 回）                                                                                                                       |
| 400  | `self_follow`              | 「自分はフォローできません。」                             | 自分をフォローしようとした                                                                                                                                                                                      |
| 400  | `invalid_csv`              | 「CSVにデータ行がありません。」ほか                        | CSV の内容のエラー（[一覧](./reference/entries.md#post-v1-imports-csv)）                                                                                                                                        |
| 400  | `invalid_request`          | 「会話内容が上限を超えているか、形式が不正です。」         | 会話練習・会話ノートで、発言の件数・字数・形が上限や決まりに合わない                                                                                                                                            |
| 401  | `unauthorized`             | 「認証が必要です。」                                       | トークンが無い・無効・期限切れ・失効（パスワードの変更など）、ログインの失敗、リフレッシュの失敗                                                                                                                |
| 403  | `forbidden`                | 「このアカウントは利用できません。」                       | admin の GitHub ID が許可リストに無い（ログイン時・リクエスト時・リフレッシュ時）                                                                                                                               |
| 403  | `forbidden`                | 「このアカウントは利用できません。」                       | ゲストのトークンで `GET /v1/me` 以外の認証つきルートを呼んだ                                                                                                                                                    |
| 403  | `forbidden`                | 「管理者だけが利用できます。」                             | 会員が admin 専用のルート（`/v1/admin/*`）を呼んだ                                                                                                                                                              |
| 403  | `forbidden`                | 「この操作は会員だけが利用できます。」                     | admin・FFPF ID の会員がパスワードの変更（`POST /v1/account/password`）を呼んだ                                                                                                                                  |
| 403  | `forbidden`                | 「共有できるのは会員だけです。」                           | admin が共有のルートを呼んだ                                                                                                                                                                                    |
| 403  | `forbidden`                | 「他の人の記録は管理者だけが見られます。」                 | 会員が `?user=` で他の人を指定した                                                                                                                                                                              |
| 403  | `forbidden`                | 「他の人として操作できるのは管理者だけです。」             | admin 以外が `X-Zhuelog-Act-As` を付けた                                                                                                                                                                        |
| 403  | `forbidden`                | 「会員として操作している間は使えません。」                 | 会員として操作している admin が LINE の連携のルートを呼んだ                                                                                                                                                     |
| 404  | `not_found`                | 「会員が見つかりません。」                                 | `X-Zhuelog-Act-As` の会員がいない                                                                                                                                                                               |
| 404  | `not_found`                | 「見つかりません。」                                       | 対象が無い、他人のもの、ゴミ箱の中（またはゴミ箱に無い）、ID の形が不正、存在しないパス                                                                                                                         |
| 404  | `not_found`                | 「アカウントが見つかりません。」                           | パスワードのリセットで会員が無い                                                                                                                                                                                |
| 404  | `not_found`                | 「会話が見つかりません。」                                 | 会話ノートが無い、他人のもの、ID の形が不正                                                                                                                                                                     |
| 405  | `method_not_allowed`       | 「このメソッドは使用できません。」                         | パスはあるがメソッドが違う。`Allow` ヘッダに使えるメソッドが入る                                                                                                                                                |
| 409  | `login_id_taken`           | 「このログインIDはすでに使われています。」                 | 会員の作成で、ログイン ID が重複した                                                                                                                                                                            |
| 413  | `too_large`                | 「リクエストが大きすぎます。」                             | 本文が 1 MiB（CSV は 4 MiB + 256 KiB）を超える                                                                                                                                                                  |
| 413  | `too_large`                | 「ファイルは4MB以下にしてください。」                      | CSV ファイルが 4 MiB を超える                                                                                                                                                                                   |
| 429  | `rate_limited`             | 「しばらくしてから再度お試しください。」                   | `/v1/auth/*`（ゲストを含む）と `/v1/account/password` のレート制限（IP ごとに 1 分 10 回）、パスワードログインの試行回数の超過（15 分で同じクライアントから 20 回・同じクライアントから同じ `loginId` へ 5 回） |
| 500  | `internal`                 | 「サーバーでエラーが発生しました。」                       | その他（DB の障害など）。詳細はログにだけ出る                                                                                                                                                                   |
| 502  | `github_unavailable`       | 「GitHub に接続できませんでした。」                        | GitHub ログインで、GitHub に届かない・タイムアウト・5xx・応答が不正                                                                                                                                             |
| 502  | `ffpf_unavailable`         | 「FFPF ID に接続できませんでした。」                       | FFPF ID のログイン（`POST /v1/auth/ffpf`）で、portal に届かない・タイムアウト（10 秒）・リダイレクト・5xx・JWKS が取れない                                                                                      |
| 502  | `chat_failed`              | 「ChatGPTから応答を受信できませんでした。」                | 会話練習で、回答を書き始める前に OpenAI に届かない・タイムアウト・失敗した（書き始めた後の失敗は NDJSON の `error` の行）                                                                                       |
| 503  | `unavailable`              | 「サービスを利用できません。」                             | `/health`・`/healthz` で DB に届かない                                                                                                                                                                          |
| 503  | `unavailable`              | 「サービスを利用できません。」                             | `POST /v1/auth/ffpf` で、API に FFPF ID の設定（`FFPF_ID_*`）が無い                                                                                                                                             |

## アプリでの扱い方

| 受け取ったもの                      | おすすめの動き                                                                                     |
| ----------------------------------- | -------------------------------------------------------------------------------------------------- |
| `401`（ログインとリフレッシュ以外） | `POST /v1/auth/refresh` を 1 回試し、成功したら元のリクエストをやり直す                            |
| リフレッシュの `401`・`403`         | 手元のトークンを捨ててログイン画面へ（パスワードの変更・リセット、許可リスト外し、トークンの盗用） |
| `403`（それ以外）                   | その操作を表示しない・`message` を見せる                                                           |
| `429`                               | 少し待ってからやり直す（レート制限は 1 分、パスワードログインの試行回数は最長 15 分）              |
| `500`・`502`・`503`                 | `message` を見せ、利用者の操作でやり直せるようにする                                               |

認証つきのどのルートでも、トークンの確認で `401 unauthorized` や `403 forbidden`（許可リストから外れた admin）が返ることがあります。各ルートのエラーの表では、そのルートに特有のものを中心に書いています。

## チェックの順番

1 つのリクエストに複数の問題があるときは、先に行うチェックのエラーが返ります。おおむね次の順です（細かい順番はルートによって少し違います）。

1. パスとメソッド（`404`・`405`）
2. レート制限（`429`。対象のルートだけ）
3. トークンの確認（`401`・`403`）と `X-Zhuelog-Act-As`（`403`・`400`・`404`）
4. `?user=` を受け付けないルートでの `?user=`（`400`）
5. 役割の確認（admin 専用・会員専用の `403`）
6. 本文の読み取りと入力の検証（`413`・`400`）
7. 対象の有無（`404`）
