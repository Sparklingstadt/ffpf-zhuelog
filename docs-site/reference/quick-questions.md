# クイック質問と質問ノート

中国語学習の疑問を1回だけ質問し、質問と回答を質問ノートに残します。会話ノートとは独立した記録です。会員と管理者が自分のノートを利用でき、ゲストは `403`、`?user=` は `400` になります。`OPENAI_API_KEY` が未設定の場合は各ルートが `404` になります。

## POST /v1/quick-question

```json
{ "messages": [{ "role": "user", "text": "了と过はどう違う？" }] }
```

`user` の1発言だけを受け付けます。質問は4,000文字以内、本文は256 KiB以内です。既存の会話と同じ NDJSON の `delta` / `done` / `error` で回答を流します。完了しなかった回答は `done` にせず、質問ノートにも保存しません。接続を切ると生成を停止します。APIキー・モデルの設定は会話練習と共通です。

## PUT /v1/questions/{id}

完全な回答を受信した後、Web が以下を送信します。`id` はブラウザーで生成した UUID です。

```json
{ "question": "了と过はどう違う？", "answer": "回答本文" }
```

質問は4,000文字以内、回答は20,000文字以内で、空白だけは受け付けません。所有者・モデル・保存日時はサーバーが決めます。同じIDと内容の再送は元の記録を返し、重複しません。既存の質問と回答を書き換えることはできません。他人のIDや異なる内容での再送には `404` を返します。

## GET /v1/questions

`{ "chatModel": "...", "questions": [...] }` を返します。質問ノートは保存日時の新しい順に最新100件。各項目には `id`、`question`、`modelName`、`createdAt` があり、回答本文は含みません。

## GET /v1/questions/{id}

自分の質問ノートを返します。一覧の項目に `answer` を加えた形です。他人のノート・存在しないIDは `404` です。

Web の入口は `/quick-question`、一覧は `/questions`、詳細は `/questions/{id}` です。保存できなかった場合は画面に回答を残し、「保存を再試行」から回答を生成し直さず保存できます。

公開時は Web と Go API の更新に加えて、`20261029000000_quick_questions` のマイグレーションが必要です。
