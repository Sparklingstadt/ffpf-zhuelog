# 共有

会員が自分のノートを、フォローしている人のタイムラインに出すための操作です。

- 使えるのは **会員だけ** です。admin はフォローされないので、admin が呼ぶと `403 forbidden`（「共有できるのは会員だけです。」）です。
- 対象は自分の、ゴミ箱に無いノートです。ゴミ箱の中・他人・存在しない ID は `404 not_found` です。
- `?user=` は付けられません（付けると `400`）。
- 共有したノートは、フォローしている人の [タイムライン](./follows.md#get-v1-timeline) に出ます。

## PUT /v1/entries/{id}/share

ノートを共有します。`sharedAt` が空のときだけ現在時刻を入れます。すでに共有中なら何も変えず、最初の `sharedAt` を保ちます。

- 権限：会員

**リクエスト**：本文なし。

**レスポンス** `200`：共有後の [ノート](./README.md#ノートの形)（`sharedAt` が入ったもの）。

**エラー**

| HTTP | code              | 状況                               |
| ---- | ----------------- | ---------------------------------- |
| 400  | `invalid_request` | `?user=` が付いている              |
| 401  | `unauthorized`    | トークンが無い・無効・失効         |
| 403  | `forbidden`       | admin が呼んだ                     |
| 404  | `not_found`       | 存在しない、他人のもの、ゴミ箱の中 |

## DELETE /v1/entries/{id}/share

ノートの共有をやめます（`sharedAt` を消します）。共有していないノートでも成功します。

- 権限：会員

**レスポンス** `200`：共有をやめた後の [ノート](./README.md#ノートの形)（`sharedAt` が `null`）。

**エラー**：`PUT /v1/entries/{id}/share` と同じ。
