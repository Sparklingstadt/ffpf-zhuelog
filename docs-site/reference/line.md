# LINE 連携

LINE に送った文を OpenAI で添削・翻訳し、送った人の学習ノートに追加するためのルートです。LINE の設定が無いときは、このページのルートはすべて `404 not_found` で、API は普通に起動します。

- 使えるのは会員と admin です。ゲストは `403`（`forbidden`）です。
- 連携の 3 つのルートは、admin が [会員として操作](../guide/auth.md#会員として操作する) している間は `403`（`forbidden`、「会員として操作している間は使えません。」）です。
- 連携は、1 つのアカウントに LINE が 1 つ、1 つの LINE にアカウントが 1 つです。
- 連携コードは 8 文字で、10 分だけ使えます。出すたびに、前のコードは無効になります。サーバーにはコードそのものを残さず、ハッシュだけを保存します。
- LINE のユーザー ID は、どのルートでも返しません。
- 結果は、バッチ名 `LINE` のノート（添削は `kind=correction`、翻訳は `kind=translation`）として保存します。漢字だけの文は添削、ひらがなかカタカナを含む文は中国語への翻訳です。500 文字を超える文は処理しません。
- 設定は、`LINE_CHANNEL_SECRET`・`LINE_CHANNEL_ACCESS_TOKEN`・`OPENAI_API_KEY`（3 つともか、すべて空）と `CRON_SECRET` です。手順は [Vercel へのデプロイ](../operations/deploy.md#_7-line-連携) を見てください。

## POST /v1/line/webhook

LINE の Messaging API からの通知を受け取ります。LINE のサーバーだけが呼びます。

- 権限：公開（`X-Line-Signature` の署名で確かめます）

署名は、本文を読む前の生のバイト列に対して、チャネルシークレットで HMAC-SHA256 を計算し、定数時間で比べます。署名が無い・合わないときは、本文を解析せずに `401` です。

署名が合えば、個々のイベントの処理が失敗しても `200` を返します（LINE が再送しないようにするためです）。処理が終わらなかったメッセージは `pending` のまま残り、[`GET /v1/line/drain`](#get-v1-line-drain) が拾い直します。

1 回の通知の処理は、リクエストの開始から 45 秒までです。残りが 30 秒を切ってから届いた文は、保存だけして OpenAI は呼ばず、「時間がかかっています」の案内を返します（文は失われず、翌朝の拾い直しが処理します）。

**レスポンス** `200`

```json
{}
```

**エラー**

| HTTP | code              | 状況                                         |
| ---- | ----------------- | -------------------------------------------- |
| 400  | `invalid_request` | 署名は合ったが、本文が LINE の通知の形でない |
| 401  | `unauthorized`    | 署名が無い・合わない                         |
| 404  | `not_found`       | LINE の設定が無い                            |
| 413  | `too_large`       | 本文が 1 MiB を超えている                    |

## GET /v1/line/link

自分が LINE と連携しているかを返します。

- 権限：会員・admin

**レスポンス** `200`

```json
{ "linked": true }
```

**エラー**

| HTTP | code              | 状況                       |
| ---- | ----------------- | -------------------------- |
| 400  | `invalid_request` | `?user=` が付いている      |
| 401  | `unauthorized`    | トークンが無い・無効・失効 |
| 403  | `forbidden`       | ゲスト                     |
| 404  | `not_found`       | LINE の設定が無い          |

## POST /v1/line/link-code

連携コードを出します。コードは、この応答でしか見られません。

- 権限：会員・admin

**リクエスト**：本文なし。

**レスポンス** `200`

```json
{ "code": "ABCD2345", "expiresAt": "2026-10-23T03:14:05.678Z" }
```

| フィールド  | 内容                                                          |
| ----------- | ------------------------------------------------------------- |
| `code`      | 8 文字の連携コード。LINE のトークに、そのまま送ってもらいます |
| `expiresAt` | 有効期限（出してから 10 分後）                                |

コードを LINE に送ると、LINE と今のアカウントが結びつき、返信が届きます。すでに別のアカウントに結びついた LINE で送ったときは、連携先が切り替わります。コードが違う・期限切れのときは、返信でそのことを伝えます。同じ LINE からの失敗は 1 時間に 5 回までで、超えると 1 時間は「連携コードの試行が多すぎます。しばらくしてから試してください。」とだけ返します。

**エラー**

| HTTP | code              | 状況                       |
| ---- | ----------------- | -------------------------- |
| 400  | `invalid_request` | `?user=` が付いている      |
| 401  | `unauthorized`    | トークンが無い・無効・失効 |
| 403  | `forbidden`       | ゲスト                     |
| 404  | `not_found`       | LINE の設定が無い          |

## DELETE /v1/line/link

連携を解除します。連携していないときも成功します。

- 権限：会員・admin

**レスポンス** `204`（本文なし）

**エラー**

| HTTP | code              | 状況                       |
| ---- | ----------------- | -------------------------- |
| 400  | `invalid_request` | `?user=` が付いている      |
| 401  | `unauthorized`    | トークンが無い・無効・失効 |
| 403  | `forbidden`       | ゲスト                     |
| 404  | `not_found`       | LINE の設定が無い          |

## GET /v1/line/drain

結果が出ないまま `pending` で残ったメッセージを拾い直します。Vercel Cron が 1 日 1 回（`0 21 * * *`、UTC なので日本時間の毎日 06:00）呼びます。

- 権限：公開（`Authorization: Bearer <CRON_SECRET>` で確かめます）

`CRON_SECRET` と定数時間で比べます。一致しない・ヘッダーが無いとき、`CRON_SECRET` が空のときは、何もせず常に `401` です。

一致したときは、先に古い行と期限切れの連携コードを削除してから、5 分以上 `pending` のメッセージを古い順に 1 回だけ試し直します。できたらノートに保存して push で知らせ、できなければ失敗を push で知らせます。1 回の実行は 50 秒までで、残りが 30 秒を切ったら新しい生成は始めず、次の実行に回します。試す回数を使い切った行は、生成せずに失敗にして push で知らせるので、残り時間が短くても処理します。

**レスポンス** `204`（本文なし）

**エラー**

| HTTP | code           | 状況                                                  |
| ---- | -------------- | ----------------------------------------------------- |
| 401  | `unauthorized` | `Authorization` が無い・合わない、`CRON_SECRET` が空  |
| 404  | `not_found`    | LINE の設定が無い                                     |
| 500  | `internal`     | 拾い直しの失敗（DB の障害など。詳細はログにだけ出る） |
