# 会員の管理（admin）

admin がパスワード会員を一覧・作成し、パスワードをリセットするためのルートと、AI の利用量を月ごとに見るルートです。Web の管理画面と同じ規則で動きます。

- 使えるのは **admin だけ** です。会員が呼ぶと `403 forbidden`（「管理者だけが利用できます。」）です。`?user=` は付けられません（付けると `400`）。
- 返したパスワードは、その応答の 1 回だけしか見られません。ログにも出しません。
- 会員の削除はありません（Web にもありません）。

## 入力の検証

| フィールド    | 規則                                                                                                                   | 違反したときの `message`                                           |
| ------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `loginId`     | 前後の空白を除いて小文字にし（JavaScript と同じ規則。U+0130「İ」は検証で落ちる）、`^[a-z0-9._-]{3,32}$` に一致すること | 「ログインIDは英小文字・数字・. \_ - の3〜32文字にしてください。」 |
| `displayName` | 前後の空白を除いて、UTF-16 の単位で 1〜50 文字。NUL を含まない                                                         | 「表示名は1〜50文字にしてください。」                              |
| `password`    | 空（または空白だけ）なら生成する。それ以外は UTF-16 の単位で 12〜128 文字（空白は除かない）                            | 「パスワードは12〜128文字にしてください。」                        |

- 違反はすべて `400 invalid_request` で、`loginId`・`displayName`・`password` の順に確かめ、最初に違反した項目のメッセージを返します。
- 前後の空白・小文字化・文字数は、Web（zod）と同じ判定にするため JavaScript の規則に合わせています。空白は `String.prototype.trim` と同じ文字を除き、文字数は UTF-16 の単位（`length`）で数えます（絵文字など U+10000 以上の文字は 2）。
- 生成するパスワードは、ランダムな 15 バイトの base64url（20 文字）です。ハッシュは Web と同じ scrypt（N=32768, r=8, p=1）です。

## GET /v1/admin/accounts

パスワード会員を作成順（`createdAt` の昇順、同じ時刻なら `id` の昇順）に返します。ハッシュは返しません。

- 権限：admin

**レスポンス** `200`

```json
{
  "accounts": [
    {
      "id": "cmh0w1a2b0000qwer5678tyui",
      "ownerId": "password:cmh0w1a2b0000qwer5678tyui",
      "loginId": "demo",
      "displayName": "デモ",
      "createdAt": "2026-10-01T00:00:00.000Z"
    }
  ]
}
```

| フィールド | 内容                                          |
| ---------- | --------------------------------------------- |
| `id`       | `PasswordAccount` の ID。リセットのパスに使う |
| `ownerId`  | `password:` + `id`。`?user=` やフォローに使う |

**エラー**

| HTTP | code              | 状況                                                                                                     |
| ---- | ----------------- | -------------------------------------------------------------------------------------------------------- |
| 400  | `invalid_request` | `?user=` が付いている                                                                                    |
| 401  | `unauthorized`    | トークンが無い・無効・失効                                                                               |
| 403  | `forbidden`       | 「管理者だけが利用できます。」：会員が呼んだ／「このアカウントは利用できません。」：許可リスト外の admin |

## POST /v1/admin/accounts

パスワード会員を作ります。

- 権限：admin

**リクエスト**

```json
{ "loginId": "new.member", "displayName": "新しい会員", "password": "" }
```

`password` は省略するか空にすると生成します。規則は [入力の検証](#入力の検証) のとおりです。

**レスポンス** `201`

```json
{
  "account": {
    "id": "cmh0x9z8y0000mnbv4321lkjh",
    "ownerId": "password:cmh0x9z8y0000mnbv4321lkjh",
    "loginId": "new.member",
    "displayName": "新しい会員",
    "createdAt": "2026-10-21T08:00:00.000Z"
  },
  "password": "Xq3v9LmZ0aB7cD1eF2gH",
  "generated": true
}
```

`password` は保存したパスワード（送ったもの、または生成したもの）、`generated` は生成したかどうかです。

**エラー**

| HTTP | code              | 状況                                                    |
| ---- | ----------------- | ------------------------------------------------------- |
| 400  | `invalid_request` | [入力の検証](#入力の検証) に違反、JSON が不正、`?user=` |
| 401  | `unauthorized`    | トークンが無い・無効・失効                              |
| 403  | `forbidden`       | 「管理者だけが利用できます。」：会員が呼んだ            |
| 409  | `login_id_taken`  | 「このログインIDはすでに使われています。」              |

## POST /v1/admin/accounts/{id}/password

会員のパスワードをリセットします。`{id}` は `PasswordAccount` の ID（`ownerId` から `password:` を除いたもの）です。

- 権限：admin

**リクエスト**

```json
{ "password": "" }
```

`password` は省略するか空にすると生成し、それ以外は UTF-16 の単位で 12〜128 文字です。

新しいハッシュを保存し、`sessionVersion` を 1 上げます。**その会員の Web と API の既存のログインはすべて無効になります**。

**レスポンス** `200`

```json
{ "loginId": "demo", "password": "Xq3v9LmZ0aB7cD1eF2gH", "generated": true }
```

**エラー**

| HTTP | code              | 状況                                                               |
| ---- | ----------------- | ------------------------------------------------------------------ |
| 400  | `invalid_request` | 「パスワードは12〜128文字にしてください。」、JSON が不正、`?user=` |
| 401  | `unauthorized`    | トークンが無い・無効・失効                                         |
| 403  | `forbidden`       | 「管理者だけが利用できます。」：会員が呼んだ                       |
| 404  | `not_found`       | 「アカウントが見つかりません。」                                   |

## GET /v1/admin/ai-usage

OpenAI を呼んだ回数とトークン数を、1 か月（日本時間）ぶん、人・機能・モデルごとに足して返します。

- 権限：admin

記録するのは、OpenAI を呼ぶ 4 つの機能です。`feature` の値は次のとおりです。

| `feature`          | 機能                                                                  |
| ------------------ | --------------------------------------------------------------------- |
| `line`             | LINE の添削・翻訳（[LINE 連携](./line.md)。翌朝の拾い直しも含みます） |
| `chat`             | 会話練習（`POST /v1/chat`）                                           |
| `quick_question`   | クイック質問（`POST /v1/quick-question`）                             |
| `vocabulary_draft` | 単語帳の下書き（`POST /v1/vocabulary/draft`）                         |

- 1 回の呼び出しごとに、OpenAI の応答にある `usage` の入力・出力トークン数を `AiUsage` に 1 行保存します。答えが使えない形だったとき、会話を途中で止めたときも、OpenAI が数えたトークンは記録します。応答が `200` でなかった呼び出しは記録しません。
- 記録するのは、そのリクエストをした人です。admin が [会員として操作](../guide/auth.md#会員として操作する) しているときは、admin に数えます。LINE はノートを受け取る持ち主に数えます。
- 記録に失敗しても、元の機能（添削・会話など）は止めず、ログに「ai usage not recorded」と残します。入力した文や答えは記録しません。

**クエリ**：`month`（省略可）。`YYYY-MM` で、2000 年以降。省略すると、今の日本時間の月です。

**レスポンス** `200`

```json
{
  "month": "2026-11",
  "totals": [
    {
      "ownerId": "password:cmh0x5k2p0000abcd1234efgh",
      "displayName": "デモ",
      "feature": "line",
      "model": "gpt-5-mini",
      "requests": 12,
      "inputTokens": 5400,
      "outputTokens": 2100
    }
  ]
}
```

- 並びは、その月のトークン数（入力と出力の合計）が多い人から順で、同じ人の中は `feature`・`model` の順です。
- `displayName` は会員の表示名です。admin（DB に行が無い）は空文字です。
- 使われていない月は `totals` が空の配列です。

**エラー**

| HTTP | code              | 状況                                                |
| ---- | ----------------- | --------------------------------------------------- |
| 400  | `invalid_request` | 「月は YYYY-MM の形で指定してください。」、`?user=` |
| 401  | `unauthorized`    | トークンが無い・無効・失効                          |
| 403  | `forbidden`       | 「管理者だけが利用できます。」：会員が呼んだ        |
