# ゴミ箱

ゴミ箱に入れたノート（`deletedAt` があるもの）の一覧・復元・完全な削除です。ノートをゴミ箱へ入れるのは [`DELETE /v1/entries/{id}`](./entries.md#delete-v1-entries-id) です。

- admin も会員も使えます。対象は自分のノートだけで、`?user=` は付けられません（付けると `400`）。
- ゴミ箱に入れても `sharedAt` は消えません。ゴミ箱の中のノートは共有中でも一覧やタイムラインに出ず、復元すると再び共有されます。
- 自動でゴミ箱を空にする仕組みはありません。
- ゴミ箱に無い ID、他人の ID、存在しない ID は `404 not_found` です。

## GET /v1/trash

ゴミ箱のノートを、ゴミ箱に入れた時刻の新しい順に返します。

- 権限：全員

**クエリ**：`limit`・`cursor`（[ページング](./README.md#一覧の続きの取得)）

並びは `deletedAt` の降順、同じ時刻なら `id` の降順です。

**レスポンス** `200`

各要素は [ノート](./README.md#ノートの形) に `deletedAt` を足したものです。

```json
{
  "entries": [
    {
      "id": "cmh0x5k2p0000abcd1234efgh",
      "kind": "correction",
      "originalText": "我昨天去了学校。",
      "correctedText": "我昨天去学校了。",
      "pinyin": "Wǒ zuótiān qù xuéxiào le.",
      "hints": [],
      "createdAt": "2026-10-20T03:04:05.678Z",
      "sharedAt": null,
      "deletedAt": "2026-10-21T08:00:00.000Z"
    }
  ],
  "nextCursor": null
}
```

**エラー**

| HTTP | code              | 状況                               |
| ---- | ----------------- | ---------------------------------- |
| 400  | `invalid_request` | `limit`・`cursor` が不正、`?user=` |
| 401  | `unauthorized`    | トークンが無い・無効・失効         |

## POST /v1/trash/{id}/restore

ゴミ箱のノートを元に戻します（`deletedAt` を消します）。

- 権限：全員

**リクエスト**：本文なし。

**レスポンス** `200`：復元した [ノート](./README.md#ノートの形)。

**エラー**

| HTTP | code              | 状況                                 |
| ---- | ----------------- | ------------------------------------ |
| 400  | `invalid_request` | `?user=` が付いている                |
| 401  | `unauthorized`    | トークンが無い・無効・失効           |
| 404  | `not_found`       | ゴミ箱に無い、他人のもの、存在しない |

## DELETE /v1/trash/{id}

ゴミ箱のノートを完全に削除します。ヒントも一緒に消えます。元には戻せません。

- 権限：全員

**レスポンス** `204`（本文なし）

**エラー**

| HTTP | code              | 状況                                 |
| ---- | ----------------- | ------------------------------------ |
| 400  | `invalid_request` | `?user=` が付いている                |
| 401  | `unauthorized`    | トークンが無い・無効・失効           |
| 404  | `not_found`       | ゴミ箱に無い、他人のもの、存在しない |

## DELETE /v1/trash

自分のゴミ箱のノートをすべて完全に削除します。

- 権限：全員

**レスポンス** `200`：削除した件数。ゴミ箱が空なら `0` です。

```json
{ "deleted": 3 }
```

**エラー**

| HTTP | code              | 状況                       |
| ---- | ----------------- | -------------------------- |
| 400  | `invalid_request` | `?user=` が付いている      |
| 401  | `unauthorized`    | トークンが無い・無効・失効 |
