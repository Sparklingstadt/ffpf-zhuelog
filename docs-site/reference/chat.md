# 会話練習

会員と管理者が ChatGPT（OpenAI）と中国語の会話練習をし、その会話を会話ノートとして保存するためのルートです。`OPENAI_API_KEY` が無いときは、このページのルートはすべて `404 not_found` で、API は普通に起動します。

- 使えるのは会員と admin です。ゲストは `403`（`forbidden`）です。
- 会話は、いつもトークンの持ち主のものです。`?user=` は受け付けません（`400`）。
- 1 つの会話は 1〜40 発言、合計 4 万字（文字数で数えます）までです。
- OpenAI には `store: false` で送り、会話を OpenAI に残しません。会話の中身はログに出しません。
- 設定は `OPENAI_API_KEY` と、任意の `OPENAI_CHAT_MODEL`（無ければ `gpt-6.1-sol`）です。手順は [Vercel へのデプロイ](../operations/deploy.md#_8-会話練習-chatgpt) を見てください。

## POST /v1/chat

会話の続きを ChatGPT に作らせ、回答を少しずつ返します。保存はしません（保存は [`PUT /v1/conversations/{id}`](#put-v1-conversations-id)）。

- 権限：会員・admin

**リクエスト**（本文は 256 KiB まで）

```json
{
  "messages": [
    { "role": "user", "text": "你好" },
    { "role": "assistant", "text": "你好！今天想练习什么？" },
    { "role": "user", "text": "我想练习点菜。" }
  ]
}
```

| 項目              | 決まり                                                |
| ----------------- | ----------------------------------------------------- |
| `messages`        | 1〜40 件。最後は `user`                               |
| `messages[].role` | `user` か `assistant`                                 |
| `messages[].text` | 空白だけは不可。すべての `text` を合わせて 4 万字まで |

**レスポンス** `200`（`Content-Type: application/x-ndjson; charset=utf-8`）

1 行に 1 つの JSON を、届いた順に流します。

```text
{"type":"delta","text":"好的，"}
{"type":"delta","text":"我们来练习点菜吧。"}
{"type":"done"}
```

| `type`  | 意味                                                                                  |
| ------- | ------------------------------------------------------------------------------------- |
| `delta` | 回答の続きの文字（`text`）                                                            |
| `done`  | 回答が最後まで届いた。これが来ないまま終わった応答は、途中で切れたものとして扱います  |
| `error` | 回答を書き始めた後に失敗した。`message` は「ChatGPTから応答を受信できませんでした。」 |

接続を切ると、OpenAI での生成も止まります。1 回の回答は 60 秒で打ち切ります。

**エラー**（回答を書き始める前）

| HTTP | code              | 状況                                                      |
| ---- | ----------------- | --------------------------------------------------------- |
| 400  | `invalid_request` | 発言の件数・字数・形が決まりに合わない                    |
| 403  | `forbidden`       | ゲスト                                                    |
| 404  | `not_found`       | `OPENAI_API_KEY` が無い                                   |
| 413  | `too_large`       | 本文が 256 KiB を超えている                               |
| 502  | `chat_failed`     | OpenAI に届かない・時間切れ・認証の失敗・レート制限・失敗 |

## GET /v1/conversations

自分の会話ノートを、会話を始めた時刻の新しい順に 100 件まで返します。発言は含みません。

- 権限：会員・admin

**レスポンス** `200`

```json
{
  "chatModel": "gpt-6.1-sol",
  "conversations": [
    {
      "id": "0b0c6f4e-5d2a-4c1b-9e3f-7a8b9c0d1e2f",
      "title": "我想练习点菜。",
      "modelName": "gpt-6.1-sol",
      "ended": false,
      "createdAt": "2026-10-24T01:02:03.000Z",
      "updatedAt": "2026-10-24T01:05:00.000Z"
    }
  ]
}
```

`chatModel` は、`POST /v1/chat` が今使うモデルの名前です。`ended` は、上限に達して読むだけになった会話です。

## GET /v1/conversations/{id}

会話ノート 1 件を、発言つきで返します。

- 権限：会員・admin

**レスポンス** `200`：一覧の項目に `messages`（`[{ "id", "role", "text" }]`）を足したもの。

**エラー**

| HTTP | code        | 状況                                        |
| ---- | ----------- | ------------------------------------------- |
| 404  | `not_found` | 会話が無い、他人のもの、`id` が UUID でない |

## PUT /v1/conversations/{id}

会話ノートをまるごと保存します。無ければ作り、あれば置き換えます。`id` はクライアントが作る UUID（小文字）です。

- 権限：会員・admin

**リクエスト**

```json
{
  "title": "我想练习点菜。",
  "modelName": "gpt-6.1-sol",
  "ended": false,
  "createdAt": "2026-10-24T01:02:03.000Z",
  "messages": [
    { "id": "m1", "role": "user", "text": "我想练习点菜。" },
    { "id": "m2", "role": "assistant", "text": "好的，我们来练习点菜吧。" }
  ]
}
```

| 項目              | 決まり                                                            |
| ----------------- | ----------------------------------------------------------------- |
| `title`           | 1〜100 字（前後の空白は除きます）                                 |
| `modelName`       | 1〜150 字                                                         |
| `createdAt`       | ISO 8601。最初の保存の値を残し、後の保存では変えません            |
| `messages`        | 1〜40 件。最後はどちらの `role` でも構いません                    |
| `messages[].id`   | 1〜200 字。会話の中で重ならない                                   |
| `messages[].text` | 空白だけは不可。すべての `text` を合わせて 4 万字まで             |
| （最後の回答）    | 最後が `assistant` なら、その `text` は 4 万字に数えず 2 万字まで |

`updatedAt` はサーバーが付けます。

**レスポンス** `200`：保存した会話（`GET /v1/conversations/{id}` と同じ形）。

**エラー**

| HTTP | code              | 状況                                     |
| ---- | ----------------- | ---------------------------------------- |
| 400  | `invalid_request` | 項目が決まりに合わない、未知のフィールド |
| 404  | `not_found`       | `id` が他人の会話、`id` が UUID でない   |

## DELETE /v1/conversations/{id}

会話ノートを消します。ゴミ箱はなく、元に戻せません。

- 権限：会員・admin

**レスポンス** `204`

**エラー**

| HTTP | code        | 状況                                        |
| ---- | ----------- | ------------------------------------------- |
| 404  | `not_found` | 会話が無い、他人のもの、`id` が UUID でない |
