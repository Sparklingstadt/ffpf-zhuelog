# ヘルスチェック

認証もレート制限もかからないルートです。

| メソッド | パス       | DB に触れる | 用途                                 |
| -------- | ---------- | ----------- | ------------------------------------ |
| GET      | `/health`  | はい        | 本番での手動の確認                   |
| GET      | `/healthz` | はい        | `/health` と同じ。ローカルでの確認用 |
| GET      | `/ping`    | いいえ      | 外部の死活監視                       |

## GET /health と GET /healthz

DB に ping（3 秒でタイムアウト）して、届けば `200` を返します。

**レスポンス** `200`

```json
{ "status": "ok" }
```

**エラー**

| HTTP | code          | 状況                                            |
| ---- | ------------- | ----------------------------------------------- |
| 503  | `unavailable` | DB に届かない（「サービスを利用できません。」） |

## GET /ping

DB にアクセスせずに `200` を返します。

**レスポンス** `200`

```json
{ "status": "ok" }
```

頻繁な死活監視には `/health` ではなく `/ping` を使ってください。数秒ごとに DB へアクセスすると、Neon のコンピュートが休止できずに費用がかかり続けるためです。
