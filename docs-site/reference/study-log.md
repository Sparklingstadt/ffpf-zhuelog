# 学習ログ

会員と admin の、日本時間の日ごとの学習量を返すルートです。Web の `/study-log` のカレンダーが使います。

- 使えるのは会員と admin です。ゲストは `403`（`forbidden`）です。
- いつもトークンの持ち主の記録です。管理者が会員として操作しているときは、その会員の記録です。

### GET /v1/study-log

`from` から `to` まで（どちらも `YYYY-MM-DD`、両端を含み、93 日まで）の、日本時間の日ごとの数を返します。何もしなかった日は含みません。

- 権限：会員・admin

**レスポンス** `200`

```json
{
  "days": [
    {
      "date": "2026-11-02",
      "reviews": 5,
      "practiceQuestions": 25,
      "notes": 1,
      "words": 2
    }
  ]
}
```

| 項目                | 数えるもの                                                    |
| ------------------- | ------------------------------------------------------------- |
| `reviews`           | [復習](./reviews.md)で答えた回数                              |
| `practiceQuestions` | 保存した介詞・補語の[練習の記録](./practice.md)の問題数の合計 |
| `notes`             | その日に足した学習ノートの数（ゴミ箱のものは数えません）      |
| `words`             | その日に[単語帳](./vocabulary.md)に入れた単語の数             |

`from` か `to` が無い・日付でない、`to` が `from` より前、94 日以上のときは `400` です。
