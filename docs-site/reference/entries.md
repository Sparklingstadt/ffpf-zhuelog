# ノート

学習ノート（`LearningEntry`）とヒント（`Hint`）の読み書きです。返すノートの形は [ノートの形](./README.md#ノートの形) を参照してください。

ゴミ箱の中のノートは、一覧・詳細・編集・ゴミ箱への移動の対象になりません（`404`）。ゴミ箱の操作は [ゴミ箱](./trash.md) にあります。

## 入力の検証

作成（`POST /v1/batches`）と編集（`PATCH /v1/entries/{id}`）で共通です。

| フィールド      | 規則                                                                      |
| --------------- | ------------------------------------------------------------------------- |
| `kind`          | `correction` か `translation`。作成時に省略すると `correction`            |
| `originalText`  | 前後の空白を除いて空でなく、2,000 文字以内。NUL を含まない                |
| `correctedText` | 同上                                                                      |
| `pinyin`        | 同上                                                                      |
| `hints`         | 文字列の配列。20 件まで。各要素は前後の空白を除いて空でなく、500 文字以内 |

- `originalText`・`correctedText`・`pinyin` は CSV のインポートと同じく 3 つとも必須です。
- ヒントの `position` はサーバーが配列の順に 0 から振ります。
- 違反はすべて `400 invalid_request`（「リクエストが不正です。」）です。どの項目が違反かは返しません。

## GET /v1/entries

自分のノートを新しい順に返します。

- 権限：全員
- `?user=`：可（[admin による閲覧](./README.md#会員のノートの閲覧)）

**クエリ**：`limit`・`cursor`（[ページング](./README.md#一覧の続きの取得)）、`user`

並びは `createdAt` の降順、同じ時刻なら `id` の降順です。

**レスポンス** `200`

```json
{
  "entries": [
    {
      "id": "cmh0x5k2p0000abcd1234efgh",
      "kind": "correction",
      "originalText": "我昨天去了学校。",
      "correctedText": "我昨天去学校了。",
      "pinyin": "Wǒ zuótiān qù xuéxiào le.",
      "hints": [],
      "createdAt": "2026-10-20T03:04:05.678Z",
      "sharedAt": null
    }
  ],
  "nextCursor": "MTc5MjQ2NTQ0NTY3OHxjbWgweDVrMnAwMDAwYWJjZDEyMzRlZmdo"
}
```

**エラー**

| HTTP | code              | 状況                                                     |
| ---- | ----------------- | -------------------------------------------------------- |
| 400  | `invalid_request` | `limit`・`cursor`・`user` が不正                         |
| 401  | `unauthorized`    | トークンが無い・無効・失効                               |
| 403  | `forbidden`       | 会員が `?user=` で他の人を指定した／許可リスト外の admin |

## GET /v1/entries/{id}

ノートを 1 件返します。

- 権限：全員
- `?user=`：可

**レスポンス** `200`：[ノート](./README.md#ノートの形) 1 件。

**エラー**

| HTTP | code              | 状況                                                                  |
| ---- | ----------------- | --------------------------------------------------------------------- |
| 400  | `invalid_request` | `user` が不正                                                         |
| 401  | `unauthorized`    | トークンが無い・無効・失効                                            |
| 403  | `forbidden`       | 会員が `?user=` で他の人を指定した                                    |
| 404  | `not_found`       | 存在しない、他人のもの、ゴミ箱の中、ID の形が不正（128 バイト超など） |

## POST /v1/batches

ノートを 1〜500 件まとめて作ります。

- 権限：全員
- `?user=`：不可

**リクエスト**

```json
{
  "entries": [
    {
      "kind": "correction",
      "originalText": "我昨天去了学校。",
      "correctedText": "我昨天去学校了。",
      "pinyin": "Wǒ zuótiān qù xuéxiào le.",
      "hints": ["了の位置"]
    }
  ]
}
```

各要素の規則は [入力の検証](#入力の検証) のとおりです。`kind` と `hints` は省略できます。

1 つのトランザクションで、インポートのバッチ（`ImportBatch`。`fileName` は `mobile:<UTC の ISO 8601 日時>`、`rowCount` は件数）を 1 件作り、ノートを入れます。1 件でも検証に失敗すれば、何も保存しません。

**レスポンス** `201`

```json
{
  "batch": {
    "id": "cmh0x5k2o0000wxyz9876abcd",
    "importedAt": "2026-10-20T03:04:05.678Z"
  },
  "entries": [
    {
      "id": "cmh0x5k2p0000abcd1234efgh",
      "kind": "correction",
      "originalText": "我昨天去了学校。",
      "correctedText": "我昨天去学校了。",
      "pinyin": "Wǒ zuótiān qù xuéxiào le.",
      "hints": [
        {
          "id": "cmh0x5k2p0001abcd1234efgh",
          "content": "了の位置",
          "position": 0
        }
      ],
      "createdAt": "2026-10-20T03:04:05.678Z",
      "sharedAt": null
    }
  ]
}
```

**エラー**

| HTTP | code              | 状況                                                    |
| ---- | ----------------- | ------------------------------------------------------- |
| 400  | `invalid_request` | 件数が 0 か 501 以上、検証エラー、JSON が不正、`?user=` |
| 401  | `unauthorized`    | トークンが無い・無効・失効                              |
| 413  | `too_large`       | 本文が 1 MiB を超える                                   |

## PATCH /v1/entries/{id}

ノートの一部を書き換えます。

- 権限：全員
- `?user=`：不可

**リクエスト**

`kind`・`originalText`・`correctedText`・`pinyin`・`hints` のうち、送ったものだけを変えます。`hints` を送ると既存のヒントを消して配列の順に入れ直します（`[]` ならヒントをすべて消します）。項目が 1 つも無い本文は `400` です。

```json
{
  "correctedText": "我昨天去学校了。",
  "hints": ["了の位置", "時間詞は動詞の前"]
}
```

1 つのトランザクションで更新します。

**レスポンス** `200`：更新後の [ノート](./README.md#ノートの形)。

**エラー**

| HTTP | code              | 状況                                                  |
| ---- | ----------------- | ----------------------------------------------------- |
| 400  | `invalid_request` | 項目が無い、検証エラー、`null`、JSON が不正、`?user=` |
| 401  | `unauthorized`    | トークンが無い・無効・失効                            |
| 404  | `not_found`       | 存在しない、他人のもの、ゴミ箱の中                    |
| 413  | `too_large`       | 本文が 1 MiB を超える                                 |

## DELETE /v1/entries/{id}

ノートをゴミ箱へ移します（`deletedAt` に現在時刻を入れます）。完全には消えないので、[復元](./trash.md#post-v1-trash-id-restore) できます。

- 権限：全員
- `?user=`：不可

**レスポンス** `204`（本文なし）

**エラー**

| HTTP | code              | 状況                                     |
| ---- | ----------------- | ---------------------------------------- |
| 400  | `invalid_request` | `?user=` が付いている                    |
| 401  | `unauthorized`    | トークンが無い・無効・失効               |
| 404  | `not_found`       | 存在しない、他人のもの、すでにゴミ箱の中 |

## POST /v1/imports/csv

CSV ファイルのノートを、自分のノートとしてまとめて取り込みます。解析と検証は Web の CSV インポートと同じです。

- 権限：全員（自分のノートにだけ入ります）
- `?user=`：不可

**リクエスト**

`multipart/form-data` の `csvFile` パートにファイルを入れます。`csvFile` が複数あれば最初の 1 つだけを使い、ほかのパートは無視します。

```bash
curl -X POST "$API/v1/imports/csv" \
  -H "Authorization: Bearer $TOKEN" \
  -F "csvFile=@notes.csv"
```

- ファイル名は `.csv` で終わること（大文字小文字は区別しない）。
- ファイルは 4 MiB まで。このルートだけ本文の上限は 4 MiB + 256 KiB です（マルチパートの余白を含む。Vercel の関数の 4.5 MB の上限より小さくしています）。
- サーバー全体の読み取り・書き込みの制限時間は 30 秒ですが、このルートだけは認証を通った後に 4 分まで延ばします。アップロードは 4 分以内に終えてください（超えると接続が切れます）。

**CSV の形式**

- 列は「最初の文」「添削後の文」「ピン音」「ヒント 1」〜「ヒント 100」の順です。`kind` は常に `correction` です。
- 1 行目は、3 列以上あって最初の 3 つ（前後の空白を除き小文字にしたもの）がそれぞれ「最初の文／原文／original」「添削後の文／添削文／corrected」「ピン音／拼音／pinyin」なら、見出しとして飛ばします。
- BOM は無視し、空行は飛ばし、行ごとの列数の違いを許し、各セルの前後の空白を除きます。空のヒントは捨てて位置を詰めます。
- 上限は、データ行 1,000 行、1 セル 1 万文字、ヒント 100 列、1 レコード 10 万文字です。

```text
最初の文,添削後の文,ピン音,ヒント1
我昨天去了学校。,我昨天去学校了。,Wǒ zuótiān qù xuéxiào le.,了の位置
```

すべての行を確かめてから、1 つのトランザクションでバッチ（`fileName` は送られたファイル名を 255 文字までに切ったもの）とノートを保存します。1 行でもエラーがあれば何も保存しません。

**レスポンス** `201`

```json
{
  "batch": {
    "id": "cmh0x5k2o0000wxyz9876abcd",
    "importedAt": "2026-10-20T03:04:05.678Z"
  },
  "count": 1
}
```

**エラー**

| HTTP | code              | message・状況                                                                                                                     |
| ---- | ----------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 400  | `invalid_request` | 「CSVファイルを選択してください。」：`csvFile` が無い、ファイルでない、空                                                         |
| 400  | `invalid_request` | 「拡張子が.csvのファイルを選択してください。」                                                                                    |
| 400  | `invalid_request` | 「リクエストが不正です。」：`multipart/form-data` でない、`?user=` が付いている                                                   |
| 400  | `invalid_csv`     | CSV の内容のエラー（下の表）                                                                                                      |
| 401  | `unauthorized`    | トークンが無い・無効・失効                                                                                                        |
| 413  | `too_large`       | 「ファイルは4MB以下にしてください。」：ファイルが 4 MiB を超える／「リクエストが大きすぎます。」：本文が 4 MiB + 256 KiB を超える |

`invalid_csv` の `message`（Web と同じ文言。行番号は見出しを含めた 1 始まりの CSV の行番号）：

- 「CSVの形式を確認してください。引用符が閉じていないか、1行が長すぎる可能性があります。」
- 「一度にインポートできるのは1000件までです。」
- 「CSVにデータ行がありません。」
- 「{行}行目は3列未満です。」
- 「{行}行目は上限（各項目1万文字・ヒント100列）を超えています。」
- 「{行}行目の「最初の文」「添削後の文」「ピン音」は必須です。」
