# 日付ごとの記録（カレンダー）

ノートを作った日付ごとにまとめて読むためのルートです。Web のカレンダーと日付ごとの記録の画面にあたります。

- 日付の区切りは Web と同じく **日本時間（UTC+9 固定）** です。`createdAt`（UTC）に 9 時間を足した日付で分けます。
- ゴミ箱の中のノートは数えません。
- その日の中の並びは古い順（`createdAt` の昇順、同じ時刻なら `id` の昇順）です。`number`（その日の何件目か、1 から）は保存された値ではなく、この並びの位置です。前のノートをゴミ箱に入れると、後ろのノートの番号が繰り上がります（Web と同じ）。
- 3 つとも `?user=` で [admin が会員の記録を読めます](./README.md#会員のノートの閲覧)。

**パスの形**

| パラメータ | 形                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------- |
| `{date}`   | `YYYY-MM-DD`（ゼロ埋め）。年は 2000〜9999。実在しない日付（`2026-02-30` など）や形の違いは `400`    |
| `{number}` | 1〜2147483647 の 10 進の整数（先頭に 0 を付けない）。形の違いは `400`、その日の件数を超えると `404` |

## GET /v1/log-dates

ノートがある日付と、その日の件数を新しい日付から順に返します。ページングせず、全期間を返します。

- 権限：全員
- `?user=`：可

**レスポンス** `200`

```json
{
  "dates": [
    { "date": "2026-10-21", "count": 2 },
    { "date": "2026-10-19", "count": 5 }
  ]
}
```

**エラー**

| HTTP | code              | 状況                               |
| ---- | ----------------- | ---------------------------------- |
| 400  | `invalid_request` | `user` が不正                      |
| 401  | `unauthorized`    | トークンが無い・無効・失効         |
| 403  | `forbidden`       | 会員が `?user=` で他の人を指定した |

## GET /v1/log-dates/{date}/entries

その日のノートを古い順に返します。各ノートに `number` を足します。

- 権限：全員
- `?user=`：可

**レスポンス** `200`

```json
{
  "date": "2026-10-21",
  "entries": [
    {
      "id": "cmh0x5k2p0000abcd1234efgh",
      "kind": "correction",
      "originalText": "我昨天去了学校。",
      "correctedText": "我昨天去学校了。",
      "pinyin": "Wǒ zuótiān qù xuéxiào le.",
      "hints": [],
      "createdAt": "2026-10-21T00:30:00.000Z",
      "sharedAt": null,
      "number": 1
    }
  ]
}
```

ノートが無い日は `entries` が `[]` です（`404` ではありません）。

**エラー**

| HTTP | code              | 状況                               |
| ---- | ----------------- | ---------------------------------- |
| 400  | `invalid_request` | `{date}` や `user` が不正          |
| 401  | `unauthorized`    | トークンが無い・無効・失効         |
| 403  | `forbidden`       | 会員が `?user=` で他の人を指定した |

## GET /v1/log-dates/{date}/entries/{number}

その日の `number` 件目のノートを返します。Web の「前へ・次へ」の画面にあたります。

- 権限：全員
- `?user=`：可

**レスポンス** `200`

```json
{
  "entry": {
    "id": "cmh0x5k2p0000abcd1234efgh",
    "kind": "correction",
    "originalText": "我昨天去了学校。",
    "correctedText": "我昨天去学校了。",
    "pinyin": "Wǒ zuótiān qù xuéxiào le.",
    "hints": [],
    "createdAt": "2026-10-21T00:30:00.000Z",
    "sharedAt": null
  },
  "number": 1,
  "total": 2
}
```

`total` はその日のノートの件数です。

**エラー**

| HTTP | code              | 状況                                                |
| ---- | ----------------- | --------------------------------------------------- |
| 400  | `invalid_request` | `{date}`・`{number}`・`user` が不正                 |
| 401  | `unauthorized`    | トークンが無い・無効・失効                          |
| 403  | `forbidden`       | 会員が `?user=` で他の人を指定した                  |
| 404  | `not_found`       | `{number}` がその日の件数を超える（0 件の日を含む） |
