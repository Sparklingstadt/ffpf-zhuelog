# 収益化までのロードマップ

学习録を、個人開発の無料アプリから、お金を払ってくれる人がいるサービスにするまでの道筋です。機能の順番は [ロードマップ](roadmap.md) と同じ「今」「次」「いつか」の 3 段で並べ、各段の終わりに「次へ進むかを決める基準」を置きます。基準を満たさなければ、無理に次へ進まず、その段をやり直すか、収益化そのものをやめることも選びます。

ここに書いた金額・数値は、2026 年 11 月時点の仮定です。確かめたら書き換えます。

## 収益化の 3 つの節目

| 節目                | 意味                                                               | 目安                  |
| ------------------- | ------------------------------------------------------------------ | --------------------- |
| 1. 初めての売上     | 自分以外の人が、1 回でもお金を払う                                 | 有料プランの契約 1 件 |
| 2. 運営費をまかなう | 毎月の支払い（Vercel・Neon・OpenAI・LINE・ドメイン）を売上で埋める | 月 5,000〜8,000 円    |
| 3. 開発時間に見合う | 機能追加や問い合わせ対応の時間が、売上で正当化できる               | 月 5 万円             |

節目 2 までが、このロードマップの範囲です。節目 3 は、節目 2 に着いたときに考え直します。

## いまの立ち位置

- **使えるのは招待制**：ID・パスワードのアカウントは管理者が `/admin/accounts` で発行し、セルフ登録はありません。FFPF ID の人だけが自分でログインできます。ゲストは介詞・補語・量詞の練習と案内だけです。
- **お金がかかっているのは AI**：LINE の添削・翻訳、ChatGPT との会話練習、クイック質問、単語帳のピンイン・意味の下書きが OpenAI（`gpt-5-mini`）を呼びます。ほかの機能（学習ノート、復習、介詞・補語・量詞の練習、読み上げ）は、ほぼ固定費だけで動きます。復習の LINE のお知らせ（v0.27.0）は OpenAI を使いませんが、LINE の月の送信数の枠を使います。
- **使った量は数え始めた**：だれが AI を何回呼び、トークンをいくつ使ったかを、v0.26.0 から記録しています（M1）。管理者は `/admin/ai-usage` で月ごとに見られます。料金を決めるには、まだ 1 か月ぶんの記録がありません。
- **売る準備がない**：利用規約・プライバシーポリシー・特定商取引法に基づく表記がなく、決済もありません。Vercel は Hobby プランなら商用利用ができないため、プランの確認が要ります。

この状態から、次の順で進めます。

## 方針

1. **AI の機能を有料にし、ノートと練習は無料のまま**にします。費用がかかるところと、人が価値を感じるところ（添削が LINE で返ってくる、会話練習ができる）が一致しているからです。
2. **まず個人の学習者に月額で売り**、先生や教室向けの売り方は、個人で売れたあとに考えます。既存の管理者・メンバーの関係（管理者がアカウントを発行し、メンバーのノートを閲覧のみで見られる）は、そのまま「先生と生徒」に使えますが、営業の相手が変わるので別の段にします。
3. **決済は Web だけ**で行います。iOS アプリを出すときも、アプリ内では売らず、Web で契約した人がログインして使う形にします（ストアの手数料と審査を避けるためです）。
4. **止められる形で作る**ことを優先します。無料枠・料金・プランの境目は設定値にし、売れなければ無料に戻せるようにします。

## 今（Now）：売る前に測る、売ってもよい状態にする（〜2026 年 12 月）

いまのユーザーに影響を与えずにできる、下ごしらえです。

### M1. AI の利用量を記録する（済み、v0.26.0）

[ロードマップ](roadmap.md) の 11 として [v0.26.0](releases/v0.26.0.md) で出しました。管理者の画面は `/admin/ai-usage` です。1 か月ぶんの記録がたまったら M2 と M4 に使います。

OpenAI を呼ぶ 4 か所（LINE 添削・翻訳、会話練習、クイック質問、単語帳の下書き）で、だれが・いつ・どの機能で・入出力トークン数いくつを使ったかを Go API の表に残します。月ごとに人別・機能別に集計できるようにし、管理者の画面か SQL で見られれば十分です。

これが無いと、無料枠の大きさも料金も決められません。

### M2. 運営費を 1 か月分、実際の数字で出す

Vercel（Web と Go API の 2 プロジェクト）、Neon、OpenAI、LINE Messaging API、ドメインの請求を 1 か月ぶん集めて、固定費と、ユーザー 1 人あたりの変動費（M1 の集計から）に分けます。

### M3. 商用利用の下地を整える

- Vercel のプランを確かめ、Hobby なら Pro（2 プロジェクトぶん）に上げる、または商用利用が許される別の置き方に変えるかを決めます。これは節目 1 より前に必要です。
- 利用規約、プライバシーポリシー（学習ノート・LINE の文・OpenAI へ送る内容の扱いを明記）、特定商取引法に基づく表記の 3 つを `/terms`・`/privacy`・`/legal` のようなログイン不要のページに置き、サイトマップに載せます。
- 問い合わせ先（メールアドレス）を決めます。

### M4. 無料枠と料金の仮説を決める

M1・M2 の数字を見て決めますが、たたき台は次のとおりです。

| プラン                   | 価格（税込） | 入るもの                                                                                                                                         |
| ------------------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 無料                     | 0 円         | 学習ノート、CSV の取り込み・書き出し、検索、復習、介詞・補語・量詞の練習、読み上げ、単語帳（AI の下書きは月 20 語まで）、LINE 添削は月 10 文まで |
| 有料（仮称：添削プラン） | 月 980 円    | 無料の全部、LINE 添削・翻訳 月 300 文まで、会話練習、クイック質問、単語帳の下書き無制限                                                          |

`gpt-5-mini` の添削 1 文は、入出力あわせて 1 円に届かない見込みです。月 300 文でも 1 人あたりの変動費は数百円に収まるはずで、M1 の実測で確かめます。

### 進み具合（2026 年 11 月 9 日）

| 項目 | 状態            | 残っていること                                                                                      |
| ---- | --------------- | --------------------------------------------------------------------------------------------------- |
| M1   | 済み（v0.26.0） | Go API の手動デプロイのあと、記録がたまるのを待つ                                                   |
| M2   | 未着手          | M1 の記録を 1 か月ためる（2026 年 12 月まで）。請求書を集める                                       |
| M3   | 未着手          | Vercel のプランの確認、規約・プライバシーポリシー・特商法の表記の文面（運営者の名前と連絡先が要る） |
| M4   | 未着手          | M1・M2 の数字を見て決める                                                                           |

M2〜M4 はコードではなく、確認・文面・判断が中心なので、まだ手を付けていません。「いつか」の M10 のうち、お知らせを送る仕組みは v0.27.0 で先に作りました（有料プランに入れるかは、まだ決めていません）。

### 「次」へ進む基準

- M1〜M3 がすべて済んでいる。
- いまの会員のうち、月に 4 日以上使う人が 3 人以上いる（自分を除く）。これを満たさないなら、売る前に「使い続ける理由」のほうが課題なので、[ロードマップ](roadmap.md) の学習機能（いまは 5 と 12）に戻ります。

## 次（Next）：登録を開き、有料プランを売る（2027 年 1〜3 月）

### M5. セルフ登録（メールアドレスでの登録）

いまはアカウントを管理者が発行しますが、お金を払う人は自分で登録できる必要があります。メールアドレスとパスワードで登録し、確認メールで有効にします。既存の ID・パスワードのアカウント（`PasswordAccount`）に、メールアドレスと確認済みの列を足す形にし、既存の会員はそのまま使えるようにします。

新規登録は、最初は招待コード付きだけにして、人数を抑えて始めます。

### M6. 無料枠を実際に効かせる

M4 で決めた上限を Go API で数え、超えたときは「今月の枠を使い切りました」と、LINE の返信・会話練習の画面・クイック質問の画面で案内します。上限は環境変数か設定表で変えられるようにし、管理者は無制限にします。

ここまでで、売れなくても OpenAI の費用が青天井にならない状態になります。

### M7. Stripe で月額を売る

Stripe Checkout と Customer Portal を使い、Go API に契約の表（`Subscription`：アカウント、Stripe の顧客 ID、プラン、期限、状態）と webhook を足します。Web には料金ページと、ヘッダーからたどれる「プラン」の画面（契約・解約・支払い方法の変更は Stripe の画面に飛ばす）を置きます。解約は次回更新日まで使える形にし、返金の方針は特商法の表記に書いたものに合わせます。

FFPF ID の会員は、学习録のアカウントに Stripe の顧客を結びつけて同じように売ります（請求を FFPF portal 側にまとめるかは、portal に決済ができたときに考え直します）。

### M8. 無料で使える入口を広げる

ゲストが試せるのは補語の練習だけです。登録前に、添削のサンプル（自分の文を 1 回だけ添削できるデモ）か、介詞・補語の練習の全モードを触れるようにして、登録する理由を作ります。[docs/x-posts.md](x-posts.md) の投稿文を、「誰でも登録できる」に書き換えます。

### 「いつか」へ進む基準（＝節目 1 と 2）

- 有料プランの契約が 1 件以上（節目 1）。
- 3 か月目の時点で、月の売上が月の運営費（M2）を上回る見込みがある（節目 2 の手前）。
- 有料会員の月の解約率が 10% 以下。

契約が 0 件のまま 3 か月たったら、価格・無料枠・入っている機能のどれが外れているかを有料化しなかった人に聞き、1 回だけ作り直します。それでも 0 件なら、有料プランは閉じて無料に戻し、収益化はいったん止めます。

## いつか（Later）：売り方を増やす（2027 年 4 月〜）

節目 2 に着いたあとの候補です。順番は決めていません。

### M9. 先生・教室向けプラン

先生が生徒のアカウントをまとめて作り、生徒のノートを閲覧のみで見られる形は、いまの管理者とメンバーの関係とほぼ同じです。これを「教室」として切り出し、生徒数で課金します（例：生徒 10 人まで月 3,000 円）。先生が添削の文に手を入れられるようにする、生徒ごとの間違いの傾向（ロードマップの 5）を見せる、が売り物になります。

### M10. 復習の LINE 通知を有料プランに入れる

お知らせそのもの（[ロードマップ](roadmap.md) の 8）は [v0.27.0](releases/v0.27.0.md) で、希望した人だけに送る無料の機能として出しました。送る前に LINE の月の送信数の残りを確かめ、30 通を拾い直しのために残します。

お知らせは LINE の push を使うので、無料プランの月 200 通では、毎朝送ると 5〜6 人で枠が尽きます。人数が増えて LINE の有料プランに上げるときは、その費用を回収するために、お知らせを有料プランに入れるかをここで決めます。

### M11. iOS アプリ

Go API はネイティブアプリ向けに作ってあります。アプリは「読む・復習する・練習する」に絞り、契約は Web で行う形にすれば、ストアの手数料は要りません。アプリ内で売るなら、Apple の手数料と審査を前提にしたプラン設計が別に要ります。

### M12. 年額プランと学習パックの販売

年額（2 か月ぶん割引）と、練習問題の追加パック（量詞、把構文などロードマップの 6）の買い切り販売です。買い切りは、月額を払いたくない人を拾います。

## 進め方の決まり

- 各項目を始めるときは、[ロードマップ](roadmap.md) の「今」にも番号を振って載せ、リリースしたらリリースノートに書きます。この文書の M 番号は変えません。
- 「次へ進む基準」を満たしたかどうかは、月の初めに 1 回だけ見ます。満たしていなくても、数字が伸びていれば 1 か月だけ延ばします。
- 料金・無料枠・プランの境目は、コードに埋め込まず設定値にします。売れなかったときに無料へ戻すのを、1 回のデプロイでできるようにするためです。

## 決めていないこと

- **価格**：980 円は仮です。M1・M2 の数字と、最初の会員 10 人に聞いた答えで決めます。
- **無料枠の数え方**：月単位か、連続した 30 日か。月単位のほうが説明しやすく、実装も Cron のリセットで済みます。
- **既存の会員の扱い**：いま使っている人は、有料化のあとも 1 年は有料プランを無料で使えるようにする案です。初期の利用者への礼と、最初のフィードバック源を失わないためです。
- **FFPF portal との役割分担**：ログインは portal にありますが、請求を portal に寄せるかは、portal に決済ができるまで決めません。
