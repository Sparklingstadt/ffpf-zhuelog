# v0.30.0 — スマホで練習の選択肢が隠れないようにし、言葉をそろえる

[ロードマップ](../roadmap.md)の 13 と 14 です。

**スマホの練習（13）**

幅 375px のスマホで介詞の練習を開くと、選択肢の下の段が y=971 にあり、下のタブ（y=731 から）の裏に隠れていました。幅 640px 未満では、介詞・補語・量詞の練習のページを次のように詰めました。これで、幅 375px・高さ 812px で問題と 4 つの選択肢がタブより上に入ります。幅 640px 以上の見た目は変わりません。

- **見出し**：英語のバッジを隠し、見出しと説明の字を小さくしました。
- **級の選択**：級のボタンを 1 行にまとめ、横にスクロールできるようにしました。「級の決め方」は練習の下へ移しました。
- **成績**：正答率・ミス・経過時間を、名前と値を横に並べて 1 行にしました。
- **問題カード**：余白、名詞の字、選択肢の高さを小さくしました。補語の練習では、カードに出していたモード名を隠しました。ページの見出しと同じだからです。
- **スクロール**：正解すると「次へ」が見えるところまで自動でスクロールし、「次へ」を押すと次の問題へ戻ります。動きを減らす設定にしている端末では、なめらかに動かさずに切り替えます。
- **ヘッダーとタブの分の余白**：ページ全体の `scroll-padding` を、上のヘッダーと下のタブの分だけ空けました。フォーカスやスクロールで出てくるものが、ヘッダーやタブの裏に入りません。今日の復習の「答えを見る」と評価のボタンも、見えていなければ見えるところまでスクロールします。

**言葉をそろえる（14）**

- **ピンイン**：「ピン音」を「ピンイン」にそろえました。次のものが対象です。
  - 画面とメッセージ
  - AI への指示文（添削・翻訳・単語の下書き・ChatGPT と話す）
  - LINE の返信の見出し（【ピンイン】）
  - CSV に書き出すときの見出し
  - サイトの説明と OGP 画像
- **CSV の取り込み**：見出しの 3 列目が「ピンイン」でも、前の書き出しの「ピン音」でも、見出しとして飛ばします。
- **OGP 画像**：描き直しました。このマシンの日本語の字体で描いたので、太さが前と少し違います。説明の文は文節の切れ目で改行します（`word-break: auto-phrase`）。
- **会話の名前**：会話を呼ぶ名前を 2 つにしました。話す画面は「ChatGPT と話す」、残った会話は「会話ノート」です。`/chat` の見出しを「会話練習」から「ChatGPT と話す」に変え、メニューの「AI に聞く」に「会話ノート」を足しました。
- **復習の文**：ホームの復習カードと、今日の復習が空のときの文に、「復習に入れた学習ノート」を足しました。

**デプロイ前に必要な作業**

マイグレーションはありません。今回は Web と Go API の両方が変わるので、**Go API を先に**デプロイしてください。新しい Web は CSV を「ピンイン」の見出しで書き出しますが、前の Go API はその見出しを知りません。Web だけが先に出ると、書き出した CSV を取り込み直したときに、見出しの行が学習ノートとして入ってしまいます。

**デプロイ後に必要な作業**

1. スマホ（幅 375px 前後）で介詞の練習を開き、選択肢がすべて下のタブの上に見えること、正解すると「次へ」が見えることを確かめてください。
2. メニューの「AI に聞く」に「会話ノート」があること、`/chat` の見出しが「ChatGPT と話す」であることを確かめてください。

検証:

- TypeScript の単体テスト（360 件）
- Go のテスト（DB を使う store のテスト、見出しが「ピンイン」の CSV を含む）
- 型チェック、Lint
- ブラウザー E2E（全件）。幅 375×812 で介詞・量詞・複合方向補語・「動詞から選ぶ」の問題と選択肢がタブより上に入ること、正解後の「次へ」と次の問題が見えることを足しました。

手元のブラウザーでも、幅 375px で介詞・補語・量詞の練習を確かめました。
