# v0.31.0 — 了・过・着の練習

文法の練習に「了・过・着」を足しました。量詞に続く、[ロードマップ](../roadmap.md)の 12 の 2 つ目です。あわせて、量詞の練習も介詞・補語と同じく HSK の級で選べるようにしました。

- **了・过・着の練習**：「練習」（`/practice`）とメニューの「了・过・着の練習」（`/practice/aspect-particles`）で、文の空欄に入るものを「了・过・着・なし」の 4 つから選びます。全 48 問（4 つの答えが 12 問ずつ）から毎回 25 問です。選択肢はどの問題も同じなので、並べ替えずに毎回「了・过・着・なし」の順で出します。スマホでは、v0.30.0 のほかの練習と同じく、見出しを詰めて問題と選択肢を下のタブより上に収めます。
- **答えの決め方**：「我去了北京／我去过北京」のように 2 つとも文になる場合は、問題の上の日本語で答えを 1 つに決めています。〜た は 了、〜たことがある は 过、〜ている・〜ながら は 着 です。「なし」は、毎日の習慣、没 の否定、これからの予定、觉得・是・希望 のように助詞を付けない動詞、連動文（去超市买…）の前の動詞の後ろです。
- **正解したとき**：補語の練習と同じく、答えを入れた文・ピンイン（了 le、过 guo、着 zhe）・和訳と読み上げ、「例文の語句を単語帳に入れる」が出ます。例文のピンインでは、経験の 过 を軽声の guo と読みます。ゲストも練習でき、会員と管理者は記録が残ります。
- **記録と復習**：記録は、量詞と同じく補語の記録の表に `mode = 'aspect'` で保存し、「補語、量詞、了・过・着の練習記録」（`/practice/complements/records`、見出しを変えました）に「了・过・着」の行として出ます。間違えた問題は「今日の復習」に「了・过・着」のカードとして入ります。新しい表は作っていません。
- **HSK の級**：了・过・着と量詞の練習に、介詞・補語と同じ「すべて・HSK 4級まで・HSK 5級・HSK 6級以上」と「級の決め方」を置きました。量詞の級は語句と例文、了・过・着の級は文のいちばん難しい語で決めます。スマホでは「級の決め方」が練習の下に移ります。どちらの練習も易しい語の文が多く、5 級以上はわずかです。

| 練習（4級まで / 5級 / 6級以上） | 手作りの表 | 公式の語彙表 |
| ------------------------------- | ---------- | ------------ |
| 量詞                            | 51 / 6 / 1 | 50 / 6 / 2   |
| 了・过・着                      | 41 / 5 / 2 | 41 / 6 / 1   |

- **級の表**：公式の語彙表で決める級（`hsk-words-official.ts`）は、量詞と了・过・着の文も入れて作り直しました。手作りの表（`hsk-words.ts`）には、2 つの練習の文に出る 5 級以上の語（匹・朵・颗・粒・副・草原・远处・烤鸭・钢琴・出差・一句话）を足しました。钥匙・蛋糕・剩 は、足すと補語・介詞の 19 問の級が変わるので足していません。介詞と補語の問題の級は、どちらの決め方でも v0.29.0 と同じです。
- **Go API**：`PUT /v1/complement-records/{id}` が `mode` に `aspect` を受け付けます。詳しくは VuePress の[練習記録](../../docs-site/reference/practice.md)のリファレンスにあります。

**デプロイ前に必要な作業**

ありません。マイグレーション `20261110110000_add_complement_aspect_mode`（`mode` の CHECK に `aspect` を追加）は、Web の本番ビルドが当てます。今の Go API と両立します。

**デプロイ後に必要な作業**

1. **Web のあとに、Go API をデプロイしてください。** デプロイするまで、了・过・着の練習の記録は保存に失敗します（Go が `aspect` を知らないため `400`）。練習そのものはできます。
2. 本番の Web で、了・过・着の練習を 1 回最後まで解き、「記録に保存しました」と出ること、「補語、量詞、了・过・着の練習記録」に「了・过・着」の行が増えたことを確かめてください。
3. 量詞の練習で「HSK 5級」を選ぶと、問題が 6 問になることを確かめてください。

検証: TypeScript の単体テスト（了・过・着の問題データの形と答えの数、出題と選択肢の順、両方の決め方での級と出題、復習での読み出し、記録の mode、量詞の級と出題、例文のピンイン、生成した級の表が最新であること、メニューの中身）、Go の全テスト（`go test -race`、実際の Postgres で `aspect` の CHECK を確かめるストアのテストを含む）、型チェック、Lint、ブラウザー E2E（全 200 件、chromium と mobile-chromium。了・过・着の 25 問を解いて記録と復習に入ること、ゲストの練習と選択肢の順、了・过・着と量詞の HSK の級と級の決め方、スマホで問題と選択肢が下のタブより上に収まること）。手元の E2E のスクリーンショットで、スマホ幅の見え方を確かめました。
