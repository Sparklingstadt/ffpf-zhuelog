# v0.14.0 — ID・パスワードのメンバーアカウントと、ユーザーごとの学習ノート

12人ほどの利用者が、管理者のOpenAIキーを使って添削・会話・記録の保存をできるように、GitHubログインとゲストに加えて、ID・パスワードでログインする「メンバー」を追加しました。あわせて、全員で共有していた学習ノートを、アカウントごとの記録に分けました。

- ID・パスワードでログインする `member` ロールを追加しました。メンバーは、会話練習（`/chat`）、自分の会話の保存・閲覧、CSVインポート、Typle連携のエクスポートを使えます。アカウント管理とLINE連携は使えません。
- 管理者は `/admin/accounts` でメンバーを作り、パスワードを再設定できます。パスワードは自動生成（20文字）か手入力（12〜128文字）を選べ、生成したパスワードは1回だけ表示します。削除と表示名の編集はありません。
- メンバーは `/account/password` で自分のパスワードを変えられます。変更・再設定をすると、そのアカウントの古いセッションはすぐに無効になります。
- パスワードはscryptのハッシュでDBに保存します。IDがない・パスワードが違う・ロック中のどれも、同じメッセージで失敗します。5回続けて失敗すると15分ロックします。IPごとの回数制限はないため、IDを知っている人が他人を15分ロックし続けることはできてしまいます。
- ヘッダーに、メンバーなら表示名と「パスワード変更」、管理者なら「アカウント管理」のリンクが出ます。ログイン画面にID・パスワードのフォームを追加しました。DB障害などでログインできないときは、日本語のエラー画面を出します。
- 学習ノート（CSVインポートとLINEで追加する記録）と会話記録を、アカウントごとに分けました。見られるのは本人と管理者です。管理者は「表示するユーザー」を切り替えて、他人の記録を閲覧だけできます。CSVインポートと会話の保存は、常にログイン中の本人の記録になります。
- これまでの学習ノートは、すべて管理者（GitHub ID `219588180`）のものになります。
- ゲストは、学習ノートと会話ノートを使えなくなりました。トップに会話練習への案内を出します。ゲストのボタンの文言を「ゲストとして使う」に変えました。
- LINEで追加するノートの保存先を、環境変数 `LINE_NOTE_OWNER_ID` で指定するようにしました。GitHubの数字のID（管理者）か `password:<アカウントID>`（メンバー）を指定します。LINEが有効なサーバー（Cloud Run）では必須です。未設定または不正な値のときは、OpenAIを呼ぶ前に失敗の返信を送り、ノートは作りません（`LINE_NOTE_OWNER_MISSING`）。LINEが無効なVercelでは、取り次ぐだけなので設定は要りません。
- macOS標準のbash 3.2で、`scripts/deploy-cloud-run.sh` が公開設定を空欄にすると止まる問題を直しました。

**デプロイ前に必要な作業**

1. Cloud Runを使っている場合は、先に `LINE_NOTE_OWNER_ID=219588180` を設定してください（`gcloud run services update zhuelog --region asia-northeast1 --update-env-vars LINE_NOTE_OWNER_ID=219588180`）。古いコードはこの値を読まないので、先に設定しても動作は変わりません。
2. `pnpm run db:deploy` でマイグレーション `20261007090000_password_accounts` と `20261008090000_learning_entry_owner` を適用してください。デプロイより先に行います。
3. mainへのマージでVercelにデプロイします。マイグレーションを適用してからデプロイが終わるまでの間は、古いコードが新しい必須の列に値を入れられないため、CSVインポートとLINEの保存が失敗します。この間は使わず、終わってから送り直してください。

**デプロイ後に必要な作業**

1. Cloud Runを使っている場合は、Cloud Shellで `git pull && ./scripts/deploy-cloud-run.sh` を実行して、Cloud Runを新しいコードにしてください。設定済みの値は空欄のまま進めれば今のままです。
2. 自分のLINEから1件送り、管理者の学習ノートに入ることを確認してください。
3. 管理者としてログインし、`/admin/accounts` から最初のメンバーを作ってください。
