# v0.22.0 — 補語の練習

介詞の練習と同じ仕組みで、補語（結果補語・方向補語・可能補語・程度補語）の練習ができるようにしました。`/practice/complements`（ヘッダーの「補語練習」）で、動詞と日本語の意味に合う補語を 4 つから選ぶ練習が 25 問ずつできます。ゲストも練習できます。会員と管理者の結果は記録に残り、`/practice/complements/records` で見返せます。

- 問題は、動詞（看）・日本語の意味（読んで理解する）・空欄つきの句（看（　）这本书）に対して、補語を 4 つから選びます。正解すると例文と和訳が出ます。介詞の練習と同じく、間違えた選択肢は消え、正解するまでその問題が続きます。
- 問題データは `data/中国語の補語_動詞との組み合わせと例文.csv`（131 行・379 問、結果補語・方向補語（単純・複合・派生）・可能補語・程度・様態補語）から `scripts/generate-practice-data.ts` で作ります。介詞の CSV も `data/` に入れ、同じスクリプトで作るようにしました。
- 誤答は、介詞と同じ「意味分類を共有しない語」に加えて、同じ動詞と組み合わさる補語（看懂 に対する 看完 の 完）と、正解を含む・正解に含まれる補語（懂 に対する 得懂、下 に対する 下来）を出しません。
- 介詞と補語で、画面の部品・問題づくり・Go API のハンドラとストアを共通にしました。ページは `src/app/practice/[kind]/` の 1 系統で、`prepositions` と `complements` 以外は 404 です。介詞の練習の URL・画面・文言は変わりません。
- Go API に `GET /v1/complement-records`・`GET /v1/complement-records/{id}`・`PUT /v1/complement-records/{id}` を足しました。形は `/v1/preposition-records` と同じで、介詞の記録の `id` を補語のルートで読むと `404` です。両方のルートで、問題の `questions[].noun` は `questions[].headword`（見出しの名詞・動詞）になりました。
- 記録の表を、種類（`kind`）の列を持つ `PracticeRecord` にしました。マイグレーション `20261107120000_add_practice_records` が表を作り、`PrepositionPracticeRecord` の行を `kind = 'preposition'` で写します（`noun` も `headword` に直します）。古い表はこのリリースでは消しません。
- ドキュメント（README、VuePress の練習記録のリファレンス）を更新しました。

**デプロイ前に必要な作業**

ありません。マイグレーション `20261107120000_add_practice_records` は、Web の本番ビルドが自動で本番 DB（Neon）に適用します。`PracticeRecord` の表を足して行を写すだけで、今動いている Go API（古い表に書く）と両立します。

**デプロイ後に必要な作業**

1. **Go API に、main を手動でデプロイしてください。**（v0.21.0 と同じ手順です。Deployments の Redeploy は使いません。）デプロイするまで、Web は新しい `/v1/complement-records` を呼べないので、補語の記録の保存が「記録を保存できませんでした」になります（練習はできます）。
2. 本番の Web で、`/practice/complements` を 1 回解いて記録が残ること、`/practice/prepositions/records` で以前の記録が見えることを確かめてください。
3. マージから Go API のデプロイまでの間に介詞の練習を解いた人がいれば、その記録は古い表 `PrepositionPracticeRecord` に残っています（`createdAt` がマイグレーションの後の行）。次のリリースで古い表を消す前に、マイグレーションと同じ `INSERT … SELECT` で `PracticeRecord` に写します。

検証: TypeScript の単体テスト（補語データの整合性・誤答の規則を含む）、Go の全テスト（`go test -race`、実際の Postgres を使うストアのテストを含む）、ブラウザー E2E（介詞と補語の両方で、25 問を解いて記録を見返すまで）、型チェック、Lint、本番ビルド。
