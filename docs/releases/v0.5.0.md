# v0.5.0 — システム連動のダークテーマ

- サインインを含む全ページ右上に「システム / ライト / ダーク」の切り替えを追加。
- 初期値はシステム。OSの配色変更に即時追従し、手動選択は端末に保存して別タブにも同期。
- CSP nonce付きの固定スクリプトで初期描画前にテーマを反映。保存が制限されるブラウザーでも切り替え可能。
- shadcn/uiの既存トークンを使ったグリーン系のダーク配色。ライト側の補助文字コントラストも改善。
- テーマ設定のためのDB変更・外部通信・追加依存関係なし。

検証: 単体42件、PC/モバイルE2E60件、型チェック、Lint、本番ビルド。OS追従、再読み込み、別タブ同期、キーボード操作、ストレージ拒否、初期描画、主要テキストのコントラスト比4.5以上を検証。既存のCSV・認可・LINE・個人添削テストも維持。
