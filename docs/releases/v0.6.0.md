# v0.6.0 — LINE開発モード

- 本人のLINEから `/dev` で開発モードを開始し、`/devend` で通常の中文添削に戻ります。
- 開発モード中のテキストを1通につき1件の公開GitHub Issueとして登録し、URLを返信します。タイトルは先頭行、本文は原文です。AIによる補完やコード変更は行いません。
- 公開先の告知、本人限定、署名検証、24時間の自動終了、一度限りの作成許可による重複公開防止を実装しました。
- GitHub認証情報はMacでのみ使用し、Vercelに渡しません。学習ノート・インポート履歴も作成しません。
- `/battery` は開発モード中も利用できます。Mac停止・スリープ中の処理は復帰後になります。

検証: 単体59件、E2E66件、型チェック・Lint・Turbopack本番ビルド成功。

本番: https://ffpf-zhuelog.vercel.app/

追加マイグレーション、Vercel側の `LINE_DEV_MODE_ENABLED=true`、更新したMacワーカー側の `LINE_DEV_ISSUES_ENABLED=true` が必要です。GitHubへの作成結果が不明な場合は自動再作成せず、Issue一覧の確認を案内します。
