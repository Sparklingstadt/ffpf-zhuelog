# v0.4.0 — 本人のAPIキーによる個人添削

- ゲスト／管理者が自分のOpenAI APIキーを使える `/practice` を追加。
- 添削文・ピン音・日本語のヒントを表示。キーは画面内の一時保持のみ、履歴はブラウザーに最大100件保存し、アプリDBには保存しません。
- サインイン画面に本人へのAPI課金、サーバー経由での送信、端末保存の注意書きを追加。
- 管理者用ChatGPT／LINEと認証情報を分離し、運営者のキーへのフォールバックと自動再試行を禁止。
- 入力サイズ・時間・連続送信制限、同一オリジン検証、エラーの秘匿化を追加。

検証: 型チェック・Lint・単体33件・PC/モバイルE2E44件・本番ビルド成功。API生成はモックで検証し、有料APIの実呼び出しは未実施。全体の整形チェックには既存23ファイルの指摘、既存Codex接続のTurbopack tracing警告が残っています。
