# v0.15.0 — 学習ノートと会話ノートのゴミ箱

学習ノートと会話ノートを、自分で消せるようにしました。消したノートはすぐには消えず、ゴミ箱に入るので、あとから元に戻せます。

- 学習ノートと会話ノートの詳細画面（`/logs/年/月/日/番号`、`/conversations/年/月/日/番号`）に「ゴミ箱に入れる」ボタンを追加しました。確認はなく、押すとその日の一覧に戻ります。
- ゴミ箱は、日付一覧とその日の一覧の「ゴミ箱」から開きます（`/logs/trash`、`/conversations/trash`）。ゴミ箱に入れた日時の新しい順に、100件まで表示します。
- ゴミ箱では、「元に戻す」で元の日付に戻せます。「完全に削除」と「ゴミ箱を空にする」は確認のあとでDBから消し、元に戻せません。ゴミ箱は自動では空になりません。
- ゴミ箱のノートは、ホームの最近のノート、日付一覧、その日の一覧、詳細、Typle連携のプレビューとエクスポート、会話練習の保存履歴のどこにも出ません。その日の番号と件数は、ゴミ箱にないノートだけで数え直します。
- ゴミ箱にある会話を、会話練習の画面からもう一度DBに保存すると、ゴミ箱から出て元に戻ります。
- 操作できるのは自分のノートだけです。管理者が他人の記録を表示しているときは、「ゴミ箱に入れる」もゴミ箱への入口も出ません。
- ゴミ箱に入れたあとにブラウザーの「戻る」を押すと、同じ番号の別のノートが開いてしまう問題を直しました。

**デプロイ前に必要な作業**

1. `pnpm run db:deploy` でマイグレーション `20261008120000_add_note_trash` を適用してください。デプロイより先に行います。`LearningEntry` と `ChatConversation` に、null を許す `deletedAt` 列を足すだけなので、今のコードのまま先に適用しても動作は変わりません。既存のノートはすべて、ゴミ箱にない状態のままです。

Cloud Run（LINE）は学習ノートを作るだけで `deletedAt` を読まないため、再デプロイは要りません。新しい環境変数もありません。
