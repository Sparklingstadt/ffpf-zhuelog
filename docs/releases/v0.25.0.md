# v0.25.0 — 例文のピンインと読み上げ、学習ノートの復習

練習と「今日の復習」で正解したときに、例文の上に文全体のピンインを出し、中国語を読み上げられるようにしました。学習ノートも「今日の復習」に入れられます。あわせて、スマホ・タブレットの下部メニューとヘッダーのロゴのリンク先を見直しました。[ロードマップ](../roadmap.md)の 1〜4 です。

- **例文のピンイン**（1・2）：正解すると、例文の上に「Zhè shàn mén hěn qīng, hái zi yě tuī de kāi.」のように、音節ごとに区切った声調記号付きのピンインを出します。補語・介詞の練習（[PR #134](https://github.com/Sparklingstadt/ffpf-zhuelog/pull/134)）と「今日の復習」の両方です。
- **ピンインの作り方**：例文 988 文（補語 829・介詞 159）のピンインは、`scripts/generate-example-pinyin.ts` が pinyin-pro（開発用の依存だけで、アプリには入りません）で一度だけ生成し、`src/domain/practice/example-pinyin.ts` に保存します。pinyin-pro の誤読は生成時に直します。構造助詞の「得」は de、接尾辞の「子」は zi、「儿」は r 化（鸟儿 → niǎor）として読み、そのほかの多音字（睡不着 の zháo、长得 の zhǎng、系上 の jì など約 50 語）は `scripts/lib/example-pinyin.ts` の `READING_FIXES` で直します。問題データを変えたら生成し直してください（生成し直すまで `tests/example-pinyin.test.ts` が失敗します）。
- **読み上げ**（3）：練習と復習の例文、学習ノートの添削後の文、単語帳の語句（復習ではめくったあと）の横に、再生ボタンを置きました。ブラウザーの音声合成（Web Speech API）で読み上げます。1 回目は普通の速さで、続けてもう一度押すとゆっくり（0.6 倍）読みます。中国語（zh-CN）の音声が無い端末では、ボタンを出しません。
- **学習ノートの復習**（4）：会員と管理者は、学習ノートの詳細画面の「復習に入れる」で、そのノートを「今日の復習」に入れられます（「復習から外す」で外せます）。復習では書いた文（翻訳ノートなら日本語）を見せ、添削後の中国語を思い出してからめくり、単語帳と同じ 4 段階で答えます。入れるのは選んだノートだけで、ゴミ箱にある間は復習に出さず、元に戻すと覚え具合ごと戻ります。完全に削除すると、復習の問題も消えます。
- **Go API**：`GET`・`PUT`・`DELETE /v1/entries/{id}/review` を足しました（会員・admin）。`GET /v1/reviews/due` の問題に `kind = entry`（`entry` にノート）が加わり、ゴミ箱にあるノートの問題は一覧と数に含めません。ノートの完全削除とゴミ箱を空にする操作は、その復習の問題も消します。詳しくは VuePress の[復習のリファレンス](../../docs-site/reference/reviews.md)にあります。
- **下部メニュー**：真ん中のタブを「LINE連携」から「補語練習」に変えました。補語練習はゲストも使えるので、誰にでもリンクとして出します。LINE 連携へは、ヘッダーのリンク（会員・管理者）から入ります。
- **ヘッダーのロゴ**：「学习録」のリンク先を `/chat` から `/` にしました。ゲストは `/chat` を開けない（404）ため、これまではゲストがロゴを押すと 404 になっていました。

**デプロイ前に必要な作業**

ありません。マイグレーションはありません（`ReviewItem` の `kind` には制約がないため、`entry` をそのまま入れられます）。

**デプロイ後に必要な作業**

1. **Go API に、main を手動でデプロイしてください。**（v0.21.0 と同じ手順です。Deployments の Redeploy は使いません。）デプロイするまで、学習ノートの詳細画面には「復習に入れる」が出ません（古い Go API が新しいルートに `404` を返すため、Web はボタンを隠します）。ピンインと読み上げ、ほかの復習は影響ありません。
2. 本番の Web で、補語か介詞の練習を 1 問解き、正解したときに例文の上にピンインが出ること、中国語の音声がある端末で再生ボタンが鳴ることを確かめてください。
3. 学習ノートを 1 件「復習に入れる」にして、「今日の復習」に学習ノートのカードが出ることを確かめてください。
4. スマホの幅で、下部メニューの真ん中が「補語練習」になっていることを確かめてください。

検証: TypeScript の単体テスト（全例文にピンインがあること、生成ファイルが最新であること、読みの規則、読み上げの声と速さ、学習ノートの復習のゲートウェイと操作）、Go の全テスト（`go test -race`、実際の Postgres で学習ノートの復習・ゴミ箱・完全削除を確かめるストアのテストを含む）、ブラウザー E2E（練習・復習での例文とピンイン、読み上げ、学習ノートの復習とゴミ箱、下部メニュー）、型チェック、Lint。
