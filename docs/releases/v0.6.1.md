# v0.6.1 — LINE添削返信の読みやすさを改善

Issue #11 に対応しました。

- 見出しを「元の文」「添削後」「ヒント」に統一。
- 添削文ごとに、その直下へピンインを表示。
- ヒントを番号付きでコンパクトに表示。
- 文とピンインの区切り数が一致しない場合は、誤った対応付けを避けて全文を順に表示。
- 原文・CSV・学習ノートの保存形式は変更していません。DB移行やMacワーカー再起動は不要です。

検証: 単体65件、型チェック、Lint。push前フックでPlaywright E2EとTurbopack本番ビルドも実行します。
