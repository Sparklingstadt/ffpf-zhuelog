# v0.27.0 — 量詞の練習と、復習の LINE のお知らせ

文法の練習に「量詞」を足し、復習の期日が来た朝に LINE でお知らせできるようにしました。[ロードマップ](../roadmap.md)の 6 と 8 です。

- **量詞の練習**（6）：ヘッダーの「量詞練習」（`/practice/measure-words`）で、名詞を数える量詞を 4 つから選びます。介詞と同じく名詞を大きく出し、「一（　）书」の空欄に入る量詞を選びます。全 58 問から毎回 25 問です。正解すると例文・ピンイン・和訳と読み上げ、「例文の語句を単語帳に入れる」が出ます。間違えた選択肢には、その名詞を数えられない量詞だけを使い、「个」（ほとんどの名詞に使える）や「一只狗」の「只」のように、正しくもなる量詞は混ぜていません。ゲストも練習でき、会員と管理者は記録が残ります。
- **記録と復習**：量詞の記録は、補語の記録と同じ表に `mode = 'measure'` で保存し、「補語・量詞の練習記録」に一緒に出ます。間違えた問題は「今日の復習」に「量詞」のカードとして入ります。新しい表は作っていません。
- **復習の LINE のお知らせ**（8）：「LINE 連携」（`/account/line`）に「復習のお知らせ」を置きました。「お知らせを受け取る」を押すと、「今日の復習」に答える問題がある朝（日本時間 06:00）に、LINE へ「今日の復習が N 問あります。」と 1 日 1 回送ります。問題の無い日は送りません。初めは止まっていて、連携し直すと止まった状態に戻ります。
- **LINE の送信数**：お知らせは push なので、LINE の月の送信数の枠を使います。送る前に今月の残りを LINE に問い合わせ、残りから 30 通を拾い直しの push のために残して、その範囲だけ送ります。無料プランの月 200 通では、毎朝送ると 5〜6 人ほどで枠が尽きます。人数が増えたら、LINE の有料プランを検討してください（当時の収益化までのロードマップの M10。その文書は 2026 年 11 月に [就職までのロードマップ](../job-hunting-roadmap.md) に書き換えました）。
- **Go API**：`GET /v1/line/link` が `reviewNotify` を返し、`PUT`・`DELETE /v1/line/review-notify` を足しました。毎朝の `GET /v1/line/drain` が、拾い直しのあとでお知らせを送ります。`PUT /v1/complement-records/{id}` が `mode` に `measure` を受け付けます。詳しくは VuePress の [LINE 連携](../../docs-site/reference/line.md#put-v1-line-review-notify)と[練習記録](../../docs-site/reference/practice.md)のリファレンスにあります。

**デプロイ前に必要な作業**

ありません。マイグレーション `20261110090000_add_line_review_notify`（`LineLink` に `reviewNotify`・`reviewNotifiedOn` の列を追加）と `20261110100000_add_complement_measure_mode`（`mode` の CHECK に `measure` を追加）は、main へのマージで Web の本番ビルドが自動で当てます。どちらも今の Go API と両立します。

**デプロイ後に必要な作業**

1. **Go API に、main を手動でデプロイしてください。**（v0.21.0 と同じ手順です。）デプロイするまで、量詞の練習の記録は保存に失敗し（Go が `measure` を知らないため `400`）、「LINE 連携」の画面の「お知らせを受け取る」は失敗の案内を出します。練習そのものはできます。
2. 本番の Web で、量詞の練習を 1 回最後まで解き、「記録に保存しました」と出ること、「補語・量詞の練習記録」に「量詞」の行が増えたことを確かめてください。
3. LINE と連携した会員で「お知らせを受け取る」を押し、翌朝 06:00 すぎに、復習があればお知らせが届くことを確かめてください。

検証: TypeScript の単体テスト（量詞の問題データの形・例文のピンイン・出題・復習での読み出し、LINE の設定のゲートウェイ）、Go の全テスト（`go test -race`、実際の Postgres でお知らせの対象の選び方・1 日 1 回の取り合い・`measure` の CHECK を確かめるストアのテスト、送信数の読み取り、お知らせの送り方）、型チェック、Lint。手元のブラウザーで量詞の練習を 1 回解き、記録と復習に入ることを確かめました。お知らせは、ダミーの LINE サーバーを立てた手元の Go API で、切り替えと、Cron 2 回で 1 通だけ届くことを確かめました。ストアのテストの `TestConsumeThrottleKeysAreIndependent` が 1 回だけ失敗し、3 回流し直して通りました（今回の変更とは関係しません）。ブラウザー E2E は流していません。
