# v0.29.0 — HSK の級の決め方を、手作りの表と公式の語彙表で切り替える

v0.28.0 で、介詞と補語の練習を HSK 3.0 の級（4 級まで・5 級・6 級以上）で選べるようにしました。そのときの級は、知識で作った語の表で決めていました。今回、公式の HSK 3.0 の語彙表で決める方法を足し、練習の画面で切り替えられるようにしました。[ロードマップ](../roadmap.md)の 19 です。

- **切り替え**：介詞の練習と補語の各モードの、級の選択の下に「級の決め方：手作りの表／公式の語彙表」を置きました。選んだほうは Cookie（`zhuelog_hsk_basis`、1 年）に残り、ほかの練習のページでも使います。初めは「手作りの表」で、v0.28.0 と同じ級になります。
- **公式の語彙表**：[ivankra/hsk30](https://github.com/ivankra/hsk30)（MIT）の `hsk30.csv` を `data/` に置きました。教育部の HSK 3.0 の基準（GF0025-2021）の 11,092 語から作られたものです。練習の文を、この語彙表で最長一致で区切り、文ごとにいちばん難しい語の級を `src/domain/practice/hsk-words-official.ts` に生成しておきます。アプリは文の級を引くだけです。そのため「已经」の 经 のように、易しい語の一部を難しい 1 文字と取り違えることはありません。作り直しは `node --import tsx scripts/generate-hsk-words.ts` です。
- **級の違い**：公式の語彙表は、補語の付いた形（看得见・不见・赶上 など）を 1 語として高い級に載せています。そのため、公式の語彙表で決めると補語の問題は高い級に寄ります。

| 練習（4級まで / 5級 / 6級以上） | 手作りの表    | 公式の語彙表   |
| ------------------------------- | ------------- | -------------- |
| 介詞                            | 90 / 62 / 157 | 107 / 33 / 169 |
| 結果補語                        | 71 / 18 / 11  | 49 / 22 / 29   |
| 可能補語                        | 76 / 13 / 11  | 65 / 10 / 25   |
| 程度補語                        | 59 / 15 / 26  | 60 / 13 / 27   |
| 単純方向補語                    | 60 / 20 / 20  | 55 / 11 / 34   |
| 複合方向補語                    | 56 / 23 / 21  | 45 / 23 / 32   |
| 単純方向補語の派生義            | 64 / 16 / 20  | 55 / 12 / 33   |
| 複合方向補語の派生義            | 71 / 12 / 17  | 63 / 10 / 27   |
| 動詞から選ぶ                    | 324 / 29 / 26 | 288 / 24 / 67  |

級の数え方と、手作りの表との違いは [docs/hsk-levels-official.md](../hsk-levels-official.md) にあります。

**デプロイ前に必要な作業**

ありません。Web だけの変更で、マイグレーションも Go API の変更もありません。

**デプロイ後に必要な作業**

1. 本番で、補語の練習（例：結果補語）の 6 級以上を開き、「公式の語彙表」に切り替えると問題数が変わること、別の練習を開いても「公式の語彙表」のままであることを確かめてください。

検証: TypeScript の単体テスト（両方の決め方での級と出題、公式の語彙表の読み込みと区切り、生成ファイルが最新であること）、型チェック、Lint、ブラウザー E2E（級の決め方の切り替えと、ほかの練習への引き継ぎを含む全件）。手元のブラウザーで切り替えを確かめました。
