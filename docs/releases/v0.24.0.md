# v0.24.0 — 補語練習に「動詞から選ぶ」モードを足す

補語の練習（`/practice/complements`）に、介詞の練習と同じ出し方の 8 つ目のモード「動詞から選ぶ」（`/practice/complements/verb`）を足しました。大きく動詞と日本語の意味を見せ、短い句の空欄に入る補語を 4 つから選びます。結果・方向・可能・程度のすべての補語が混ざって出て、毎回ちがう補語が 25 問出ます。既存の 7 モードと問題データは変えていません。

- 問題は `data/中国語の補語_動詞との組み合わせと例文.csv`（131 行・379 問、結果補語・方向補語（単純・複合・派生）・可能補語・程度・様態補語）から `scripts/generate-complement-verb-data.ts` で作ります。誤答は手書きではなく規則で選びます。正解と意味分類を共有しない補語のうち、その動詞と組み合わさる補語（看懂 に対する 看完 の 完）と、正解を含む・正解に含まれる補語（懂 に対する 得懂、下 に対する 下来）は出しません。
- 記録は今までの `ComplementPracticeRecord` に `mode = 'verb'` で保存します。`questions[].id` は `verb:<CSV の行 ID>:<動詞>`（例 `verb:C005:看`）、`questions[].noun` は動詞です。
- 間違えた問題は、介詞と同じく問題ごと（行と動詞）に「今日の復習」へ入ります。復習のカードは介詞と同じ見せ方（「補語」のバッジ、動詞を大きく）で、4 択は毎回組み直します。既存の 7 モードの復習カードは変わりません。
- Go API の `PUT /v1/complement-records/{id}` が `mode` に `verb` を受け付けます。マイグレーション `20261108090000_add_complement_verb_mode` が `mode` の CHECK 制約に `verb` を足します。
- README と VuePress の練習記録のリファレンスを更新しました。

**デプロイ前に必要な作業**

ありません。マイグレーション `20261108090000_add_complement_verb_mode` は、Web の本番ビルドが自動で本番 DB（Neon）に適用します。CHECK 制約を緩めるだけで、今動いている Go API と両立します。

**デプロイ後に必要な作業**

1. **Go API に、main を手動でデプロイしてください。**（v0.21.0 と同じ手順です。Deployments の Redeploy は使いません。）デプロイするまで、古い Go API は `mode = 'verb'` を `400` で拒むので、「動詞から選ぶ」の記録の保存が「記録を保存できませんでした」になります（練習はできます。他のモードと介詞は影響ありません）。
2. 本番の Web で、`/practice/complements/verb` を 1 回解いて記録が残ることと、間違えた問題がホームの「今日の復習」に出ることを確かめてください。

検証: TypeScript の単体テスト（CSV データの整合性・誤答の規則・復習の問題の復元を含む）、Go の全テスト（`go test -race`、実際の Postgres で CHECK 制約を確かめるストアのテストを含む）、ブラウザー E2E（8 モードの練習と記録、「動詞から選ぶ」の復習）、型チェック、Lint、本番ビルド。
