# v0.26.0 — 学習ノートの検索、例文から単語帳、ピンインを隠す、AI の利用量

学習ノートを語句・種類・ヒントで探せるようにし、練習と復習の例文から語句を単語帳に入れられるようにしました。例文のピンインは、最初は隠しておけます。あわせて、料金を決める準備として、OpenAI を呼んだ回数とトークン数を記録し、管理者が月ごとに見られるようにしました。[ロードマップ](../roadmap.md)の 7・9・10・11 と、当時の収益化までのロードマップの M1 です（その文書は 2026 年 11 月に [就職までのロードマップ](../job-hunting-roadmap.md) に書き換えました）。

- **学習ノートの検索**（7）：ホームの学習ノートの上に検索欄を置きました。語句（書いた文・添削後の文・ピンイン・ヒントのどれか）、種類（添削か翻訳）、ヒントで絞り込み、合う件数と新しい順の最大 100 件を出します。検索の条件は URL に入るので、そのまま共有やブックマークができます。管理者が会員の記録を見ているときは、その会員のノートを探します。
- **例文から単語帳に入れる**（9）：練習と「今日の復習」で正解したとき、例文の下の「例文の語句を単語帳に入れる」を開くと、学習ノートと同じ入力欄が出ます。例文の中を選んで「選んだ語句を入れる」、「AIで下書き」も使えます。会員と管理者だけで、ゲストには出しません。
- **例文のピンインを隠す**（10）：例文の下の「例文のピンインを最初は隠す」を付けると、正解してもピンインは「ピンインを見る」の裏に隠れます。設定はテーマと同じく、その端末のブラウザーだけに保存します（`zhuelog:example-pinyin:v1`）。和訳は例文のすぐ下に出すように並びを直しました。
- **AI の利用量**（11・M1）：LINE の添削・翻訳、ChatGPT と話す、クイック質問、単語帳の下書きで OpenAI を呼ぶたびに、だれが・どの機能で・どのモデルで・入出力のトークンをいくつ使ったかを、Go API が `AiUsage` に 1 行ずつ残します。入力した文や答えは残しません。管理者はヘッダーの「AI 利用量」（`/admin/ai-usage`）で、日本時間の月ごとに人・機能別の合計を見られます。管理者が会員として操作しているときの分は、管理者に数えます。記録に失敗しても、元の機能は止めません。
- **Go API**：`GET /v1/entries` が検索の `q`・`kind`・`hint` を受け付けます（`total` も検索に合う数になります）。管理者用の `GET /v1/admin/ai-usage?month=YYYY-MM` を足しました。詳しくは VuePress の[ノート](../../docs-site/reference/entries.md#get-v1-entries)と[会員の管理](../../docs-site/reference/admin.md#get-v1-admin-ai-usage)のリファレンスにあります。

**デプロイ前に必要な作業**

ありません。マイグレーション `20261109090000_add_ai_usage`（`AiUsage` の表の追加）は、main へのマージで Web の本番ビルドが自動で当てます。表を足すだけなので、今の Go API と両立します。

**デプロイ後に必要な作業**

1. **Go API に、main を手動でデプロイしてください。**（v0.21.0 と同じ手順です。Deployments の Redeploy は使いません。）デプロイするまで、検索欄は条件を無視してすべてのノートを出し、「AI 利用量」の画面は「利用量を読めませんでした」と出し、利用量は記録されません。
2. 本番の Web で、ホームの検索欄に語句を入れ、合うノートだけが出ることを確かめてください。
3. 補語か介詞の練習を 1 問解き、「例文のピンインを最初は隠す」と「例文の語句を単語帳に入れる」が動くことを確かめてください。
4. LINE に文を 1 つ送るか、クイック質問を 1 回使ってから、管理者で「AI 利用量」を開き、その月の行が増えたことを確かめてください。

検証: TypeScript の単体テスト（検索の条件の読み取りとゲートウェイ、ピンインの設定の保存、利用量の集計とゲートウェイ）、Go の全テスト（`go test -race`、実際の Postgres で検索の絞り込みと利用量の月の集計を確かめるストアのテストを含む）、型チェック、Lint、手元のブラウザーでの検索・ピンインを隠す・例文から単語帳に入れる操作。管理者の画面は、手元では GitHub でログインできないため、ブラウザーでは確かめていません。ブラウザー E2E は流していません。
