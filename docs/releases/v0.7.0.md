# v0.7.0 — Typle復習リストとGo製LINEワーカー

- 学習ノートの添削差分とヒント内の引用語から、Typle用の復習語を自動抽出する管理者画面を追加しました。
- 中国語を表示・入力対象、元のヒント・例文・拼音を補足にした、`typle-r` v1保存形式のJSONを出力します。
- 未認証・ゲストからTyple画面と出力APIを保護し、抽出結果が空の場合は無効なリストを出力しません。
- Mac上のLINE常駐ワーカーをTypeScriptからGoへ移植しました。外部Go依存はなく、既存のclaim・lease・生成・配送・バッテリー・開発Issue処理の境界を維持します。
- CIとGitフックにGoの整形、vet、race detector付きテスト、バイナリビルドを追加しました。

DBマイグレーションとVercel環境変数の追加はありません。

Typle側には外部JSONのインポート画面がまだないため、このリリースの連携範囲は自動生成・プレビュー・互換JSON出力までです。

Goワーカーへの切替はWebデプロイとは別の運用作業です。`npm run line:worker:build` でビルドし、既存ワーカーを停止して退避した後、LaunchAgentの実行先を `build/line-worker` に更新して再登録してください。新旧ワーカーを同時に起動しないでください。

検証: Go vet・race detector付きテスト、TypeScript単体テスト、Typle自身のデコーダーによるJSON互換性確認、未認証・ゲスト・管理者のブラウザE2E、型チェック、Lint、Turbopack本番ビルド。
