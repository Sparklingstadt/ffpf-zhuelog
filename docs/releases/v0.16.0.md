# v0.16.0 — メンバーをフォローして、共有された学習ノートを読む

ほかのメンバーが共有した学習ノートを読めるように、フォローと学習ノートの共有を追加しました。あわせて、ヘッダーのログインIDの隣に、自分のロールを表示するようにしました。

- ヘッダーに「フォロー」（`/follow`）を追加しました。管理者とメンバーだけに出ます。ゲストは開けず、`/` に戻されます。
- `/follow` には、自分以外のメンバーの一覧と、［フォローする］／［フォロー解除］のボタンが並びます。自分をフォローしている人には「フォローされています」と出ます。「フォロー中 N人・フォロワー N人」の人数も出ます。フォローに承認や通知はなく、片方向です。
- フォローされるのはメンバーだけです。管理者はDBに行がないため、一覧に出ず、フォローされません。管理者がメンバーをフォローすることはできて、フォロワーの人数には数えます。
- メンバーは、自分の学習ノートの詳細画面で、1件ずつ「共有する」「共有をやめる」を切り替えられます。最初は共有されません。共有中のノートには「共有中（フォロワーが見られます）」と出ます。会話ノートは共有できません。
- `/follow` の「フォロー中の人の共有ノート」に、フォロー中の人が共有している学習ノートを、登録日時の新しい順に最新100件まで出します。ゴミ箱に入れたノートは出ません。詳細ページへのリンクは出しません。
- 管理者が他人の記録を閲覧のみで見る機能は、共有の有無に関係なく、これまでどおりです。
- ヘッダーのログインIDの隣に「ロール：管理者」「ロール：メンバー」を表示しました。ゲストには出ません。

**デプロイ前に必要な作業**

1. `pnpm run db:deploy` でマイグレーション `20261010000353_add_follows_and_shared_notes` を適用してください。デプロイより先に行います。`Follow` テーブルの追加と、`LearningEntry` への `sharedAt` 列（null を許す）の追加だけなので、既存のノートはすべて共有されないままです。

Cloud Run（LINE）は共有の列を読まないため、再デプロイは要りません。新しい環境変数もありません。

検証: TypeScript単体テスト、ブラウザーE2E（フォロー・解除、ノートの共有とタイムラインへの表示、他人のノートIDでは共有できないこと）、型チェック、Lint。
