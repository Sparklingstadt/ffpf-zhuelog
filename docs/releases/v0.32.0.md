# v0.32.0 — ログインなしで試せるデモアカウントと、ポートフォリオとしての文書

[就職までのロードマップ](../job-hunting-roadmap.md) の J1〜J4 です。

**デモアカウント（J2）**

- ログイン画面の「デモで試す」から、アカウントを持たない人も、会員向けの画面（学習ノート、今日の復習、単語帳、会話ノート、練習の記録）を試せます。中には、直近 7 日分の例のデータ（ノート 12 件、単語 10 個、会話 2 件、期日の来た復習）が入っています。
- 試す人全員で 1 つのアカウントを使います。毎晩 04:00（日本時間）に、Go API の Cron（`/v1/cron/demo-reset`）が例のデータへ戻します。
- AI（ChatGPT と話す、クイック質問、単語帳の下書き）、LINE 連携、フォローと共有、パスワード変更は、Go API が「デモでは使えません。」と断り、メニューにも出しません。どのページの上にも「デモアカウントです。」の帯が出ます。
- Go API の環境変数 `DEMO_LOGIN_ID` で有効になります。デモとして入れるのは、リセットが作った（使えるパスワードを持たない）アカウントだけです。本物の会員の ID を指定しても、その会員にパスワードなしで入れることはありません。

**デプロイ前に必要な作業**

マイグレーションはありません。Web と Go API の両方が変わります。

1. Go API の Vercel プロジェクトの Production に `DEMO_LOGIN_ID=demo` を入れます（`CRON_SECRET` は LINE のために入っています）。
2. Go API、Web の順にデプロイします。Go API のデプロイで、2 つ目の Cron が登録されます。
3. リセットを 1 回呼んで、デモのアカウントとデータを作ります：`curl -X POST https://ffpf-zhuelog-api.vercel.app/v1/cron/demo-reset -H "Authorization: Bearer $CRON_SECRET"` が 204 を返すこと。

**デプロイ後に必要な作業**

1. 本番の `/signin` に「デモで試す」が出て、押すと帯と学習ノートが出ることを確かめてください。
