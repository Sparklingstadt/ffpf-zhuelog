# v0.12.0 — LINEの添削・翻訳をMacなしで行う

LINEの添削は、Macで動くGoのワーカーがCodexで生成していたため、Macが止まっていると返信が届きませんでした。生成をVercelの中でOpenAI APIに移し、Macがなくても返信が届くようにしました。あわせて、日本語の文を中国語に訳す「翻訳」を追加しました。

- LINEに送った文の添削・翻訳は、Vercel上でOpenAI API（`gpt-5-mini`）が行います。webhookへ200を返したあと、同じ関数の中で処理して返信します。
- ひらがな・カタカナを含む日本語の文は、中国語（簡体字）に翻訳して返信します。返信は「元の文」「中国語訳」「ヒント」の見出しです。コマンドは不要です。
- 漢字を含むそれ以外の文は、今までどおり添削して返信します。500文字を超える文は、今までどおり上限を通知します。
- 学習ノートに「翻訳」の種類を追加しました。翻訳のノートは差分の色分けをせず、「中国語訳」として表示します。既存のノートとCSVの取り込みは、今までどおり添削として扱います。
- 取り残したジョブは、次のwebhookの処理と、Vercel Cron（1日1回、`/api/line/drain`）が拾い直します。生成に失敗したときは、ノートを作らずに原因コード付きの失敗の返信を送ります。生成は再試行しません（二重課金の防止）。
- Cronは1日1回（0:00 UTC）のため、締め切りで残ったジョブや、LINE配送が一時的に失敗して待ち時間に入ったジョブは、次のLINEメッセージかCronまで最大で約24時間待ちます。一時的に失敗した配送を初回の配送開始から23時間より後に再送する場合は、二重送信を防ぐために停止し（`DELIVERY_WINDOW_EXPIRED`）、この稀な場合は返信が届きません。
- 廃止しました: Macのワーカー（`workers/line/`）、`/battery`、開発モード（`/dev`・`/devend` による GitHub Issue の作成）。これらを送っても無視されます。過去のジョブ行や開発モードの表は削除していません。
- `OPENAI_API_BASE_URL` と `LINE_API_BASE_URL` を追加しました。E2Eテストが偽のOpenAI・LINEサーバーへ接続するための設定で、ループバックのアドレスだけを受け付けます。本番では設定しないでください。

**デプロイ前に必要な作業**

1. `pnpm run db:deploy` でマイグレーション `20261005090000_learning_kind_and_translation` を適用してください。デプロイより先に行います。
2. Vercelに環境変数 `CRON_SECRET` を設定してください（`openssl rand -hex 32` で生成した、32文字以上の値）。未設定または32文字未満では、Cronのルートは常に401を返し、取り残しを拾い直せません。
3. mainへのマージでVercelにデプロイします。`OPENAI_API_KEY` と LINE の既存の環境変数はそのまま使います。

**デプロイ後に必要な作業**

1. Macのワーカーを止めてください。止め忘れても、ワーカー用のAPIは廃止したので二重には処理されません。

   ```sh
   launchctl bootout gui/$(id -u)/jp.ffpf.zhuelog.line-worker
   ```

   `~/Library/LaunchAgents/jp.ffpf.zhuelog.line-worker.plist` と、Macの `.env.local` の `LINE_WORKER_URL`・`LINE_WORKER_TOKEN` も削除できます。

2. 不要になった環境変数 `LINE_WORKER_TOKEN` と `LINE_DEV_MODE_ENABLED` をVercelから削除してください（残しても害はありません）。
3. 自分のLINEから短い日本語と中文を送り、中国語訳と添削が返ることを確認してください。

Webチャットのローカル限定のCodex（`CHAT_PROVIDER=codex-local`）は変わりません。

検証: TypeScript単体テスト、ブラウザーE2E（本番ビルドのサーバーと、手元で立てた偽のOpenAI・LINEサーバーで、日本語の翻訳・中文の添削・生成失敗の返信・同時受信・Cronでの取り残しの処理を確認。実際のOpenAIとLINEには接続しません）、型チェック、Lint。
