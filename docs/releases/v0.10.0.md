# v0.10.0 — 学習カードで添削の差分を表示

学習ノートと日付別ログのカードを、「何が直されたか」が一目でわかる表示に変えました。

- 最初の文と添削後の文を文字単位で比べ、削除された文字を赤の取り消し線、追加された文字を緑の下線で示します。
- 本文を「添削前 → 添削後」の縦の流れにし、添削後の文とピン音を大きく表示します。
- 見出しに「N箇所を添削」を表示します。続けて変わった文字は1箇所に数えます。同じ文なら「添削なし」と表示します。
- ヒントは番号付きの「覚えるポイント」として並べます。長いヒントも読みやすくなります。
- 本文に重複していた最初の文の見出しと番号を整理しました。

差分は `<del>` / `<ins>` で表すため、文のテキスト自体は変わらず、コピーや検索にはそのままの文が使われます。比較する部分が約500文字を超える場合は、その部分を1つの書き換えとして表示します。

デザイン案: https://www.figma.com/design/15un6au89U06Ei76aqifeN

DBマイグレーション、Vercel環境変数の追加、Go workerの再起動は不要です。

検証: TypeScript単体テスト（差分の単体テスト5件を追加）、ブラウザーE2E、型チェック、Lint、ライト／ダーク・デスクトップ／モバイル幅での実際の画面確認。
