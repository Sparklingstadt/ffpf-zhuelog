# v0.11.0 — ChatGPTとの会話を保存して会話ノートで見返す

ChatGPTとの会話練習が記録されず、画面を離れると消えていた問題に対応しました。会話をDBに保存し、学習ノートと同じように日付ごとに見返せます（#24 の会話保存を統合）。

- 会話練習（`/chat`）に「会話を終える」「会話を保存する」「端末にダウンロード」「新しい会話」を追加しました。「クリア」はなくなりました。
  - 保存は本人のGitHub IDに紐づくDBへの手動保存です。同じ会話を再保存すると更新になり、重複しません。
  - 会話を終えると、内容を残して入力を閉じます。生成中に終えた場合も、それまでの内容は残ります。
  - 会話はLocalStorageにも自動バックアップします（最新20会話・1MiBまで）。再読み込みで進行中の会話を復元します。DB保存に失敗しても、バックアップとダウンロードは使えます。
  - ダウンロードは、発言・日時・モデル情報を含むMarkdownです。
- ホームと会話練習に「会話ノート」（`/conversations`）を追加しました。学習ノートの日付別ログと同じく、日本時間の保存日 → 日別一覧 → 詳細（前後のノートへ移動、Markdownダウンロード）の順に開けます。
- 会話は保存した本人だけが見られます。ゲストや別の管理者には表示されず、APIでも本人以外の閲覧・上書きを拒否します。
- ChatGPT（API）の既定モデルを `gpt-6.1-sol` に変更し、推論強度 `medium` を明示して送信します（本番では反映済みの設定をソースに取り込みました）。

**デプロイ前に必要な作業**

1. `pnpm run db:deploy` でマイグレーション `20261001100000_chat_conversations` と `20261004090000_chat_conversation_created_at` を適用してください。
2. Vercelの `OPENAI_MODEL` が `gpt-6.1-sol` になっていることを確認してください。
3. 既存のログインセッションにはGitHub IDが含まれないため、一度ログアウトしてGitHubでログインし直してください。

Go workerの再起動は不要です。

検証: TypeScript単体テスト、ブラウザーE2E（AI応答をモックした会話の終了・保存・復元・ダウンロード、本人以外からの保護、会話ノートの日付別閲覧）、型チェック、Lint、本番ビルド。
