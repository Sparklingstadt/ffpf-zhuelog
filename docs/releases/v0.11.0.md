# v0.11.0 — ChatGPTとの会話を会話ノートとして保存

ChatGPTとの会話練習が記録されず、画面を離れると消えていた問題に対応し、学習ノートと同じように会話を保存・見返せるようにしました。

- 会話練習（`/chat`）に「会話ノートに保存」ボタンを追加しました。押した時点の会話をデータベースへ保存します。自動保存はしません。
- 保存後に会話を続けると「ノートを更新」に変わり、同じノートを最新の会話で上書きします。「クリア」後の保存は新しいノートになります。
- 未保存の会話を「クリア」するときは確認ダイアログを表示します。
- ホームと会話練習に「会話ノート」（`/conversations`）を追加しました。学習ノートの日付別ログと同じく、日本時間の保存日 → 日別一覧 → 詳細（前後のノートへ移動）の順に開けます。
- ノートのタイトルは最初の質問の先頭40文字です。ChatGPTの応答がある会話だけを保存でき、1ノート100メッセージ・合計10万文字までです。
- 会話ノートは管理者専用です。ゲストには表示されません。

**DBマイグレーションが必要です**（`ConversationNote` / `ConversationMessage` テーブルを追加）。デプロイ前に `pnpm run db:deploy` を実行してください。Vercel環境変数の追加、Go workerの再起動は不要です。

検証: TypeScript単体テスト（会話ノートの検証・保存／更新の単体テスト6件を追加）、ブラウザーE2E（会話ノートの閲覧・ゲストからの非表示を追加）、型チェック、Lint、本番ビルド、ChatGPTの応答をモックした実際の画面での保存・更新・閲覧（デスクトップ／モバイル幅）。
