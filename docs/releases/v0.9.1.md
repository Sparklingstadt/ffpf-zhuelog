# v0.9.1 — Typle復習語の分割を修正

Typle用の復習リストで、「图书馆」が「图书」と「馆」のように分かれて抽出される問題を直しました。

- 3文字以下の中国語は分割せず、1語として扱います。Node.jsの単語区切り（ICU）は、图书馆・博物馆・电影院・服务员などを2つに分けてしまうためです。4文字以上は従来どおり単語に区切ります。
- 添削で語順を入れ替えただけの部分（去图书馆了 → 去了图书馆 の「图书馆」など）は、追加された語に数えません。元の文にある2文字以上の並びを除いて抽出します。
- ヒント内の「引用語」にも同じ扱いを適用します（「博物馆」→ 博物馆）。

サンプルCSVの復習語は「道・去・了・图书・馆」から「道・去・了」になります。2〜3文字の並びが実際には2語の場合（都很など）も、1語として扱われます。

出力JSONの形式、ファイル名、画面、URLは変わりません。DBマイグレーション、Vercel環境変数の追加、Go workerの再起動は不要です。

検証: TypeScript単体テスト91件、Go vet・race detector、ブラウザーE2E、型チェック、Lint、Turbopack本番ビルド、実際の画面でのプレビューとJSONダウンロード。
