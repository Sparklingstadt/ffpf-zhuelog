# v0.5.2 — LINEからMacのバッテリーを確認

- 本人のLINEから `/battery` を送ると、Macの残量・充電状態・取得時刻を返信します。
- AIを呼ばず、学習ノート・インポート履歴も作成しません。
- 固定の読み取り専用コマンドのみを実行し、署名検証・本人制限・lease・重複返信防止を維持しています。
- 旧ワーカーがバッテリー要求を誤処理しないよう、対応機能の申告を追加しました。
- Macがスリープ・電源OFF・ログアウト中は、復帰後に取得・返信します。LINEのPush配信枠は消費します。

本番: https://ffpf-zhuelog.vercel.app/

追加マイグレーション後にVercelとMacワーカーの両方を更新してください。

検証: 単体テスト50件、Playwright E2E 62件（デスクトップ・モバイル）、型チェック、Lint、Turbopack本番ビルドが成功。依存関係の監査も脆弱性0件です。
