# v0.10.1 — 長文の添削差分を読みやすく

v0.10.0の学習カードで、大きく書き換えた長文の差分が細切れになっていた問題を直しました。

- 文字単位の比較では、書き換えた文の中でたまたま同じ文字（「我」「个」「了」など）が一致として拾われ、1つの書き換えが多数の小さな変更に分かれていました。日記のような長文では「33箇所を添削」のように表示され、赤と緑の印が散らばって読みにくくなっていました。
- 書き換えの間に残った短い共通部分は、前後の書き換えに含めて1つの書き換えとして表示します。対象は、前後の書き換えの小さい方の半分以下の長さの部分と、2文字以上の書き換えに隣接する1文字です。
- 短い文の表示は変わりません（去图书馆了 → 去了图书馆、学中文两年 → 学了两年中文了 など）。日付の「9/26 → 9月26日」のように、1文字ずつの変更の間にある短い共通部分もそのまま残します。

本番の長文ノートでは、たとえば「33箇所を添削」が「21箇所を添削」、「20箇所を添削」が「11箇所を添削」になります。

画面の構成、URL、DBは変わりません。DBマイグレーション、Vercel環境変数の追加、Go workerの再起動は不要です。

検証: TypeScript単体テスト（差分のテスト2件を追加）、ブラウザーE2E、型チェック、Lint、実際の画面での確認。
