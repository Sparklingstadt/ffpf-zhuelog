# v0.17.0 — ChatGPT・個人添削・連携エクスポート・LINEを外す

機能を外す変更です。Web 側の API（Route Handler）が `/api/auth` だけで足りるようになったため、それを使っていたChatGPT会話、個人の添削、連携エクスポート、LINE を、画面・API・テストごと削除しました。あわせて、使わなくなったDBのテーブルとCloud Runへのデプロイ用のコードも削除しています。学習ノートの機能は変わりません。

- 削除しました（#66）:
  - ChatGPTとの会話練習（`/chat`）と会話ノート（`/conversations`）、およびその API（`/api/chat` など）。直前に入れた、会話を `CHAT_ENABLED` で切り替える変更も、この削除で不要になりました。
  - 自分のAPIキーでの添削（`/practice`、サインイン画面の「自分のAPIキーで添削」、`/api/corrections`）。
  - 連携エクスポート（`/integrations/[id]`、`/api/integrations/[id]/export`、Typle用のプラグイン）。
  - LINE連携（`/api/line/webhook`、`/api/line/drain`、`vercel.json` のCron）。
- ゲストが使えた機能は添削だけだったため、ゲストでログインしても「学習ノートを利用できません」と表示されるだけになります。
- 学習ノートとそのゴミ箱、フォローは残っています。ホームとサインイン画面から、削除した機能へのリンクを外しました。
- 保存済みのChatGPT会話とLINEのジョブは、#71 のマイグレーションで削除します（下の「デプロイ前」を参照）。スキーマからは `ChatConversation`・`LineLearningJob`・`LineDevelopmentSession` を外しました。
- Cloud Runへのデプロイ用のコードと手順（`Dockerfile`、`docs/cloud-run.md`、`scripts/deploy-cloud-run.sh` など）と、CIのDockerのジョブを削除しました（#72）。本番はVercelだけで動きます。
- `packages/core` をなくし、`domain`・`application` をアプリの `src/` に統合しました（#68）。pnpm workspaces をやめて1パッケージに戻しています。動作は変わりません。
- 記録ページとServer Actionの重複をまとめました（#70）。詳細ページの「この日のN件目／全N件」と見出しの間隔が8pxになる以外、見た目は変わりません。
- `build` を `prisma generate && next build` に変更しました。Vercelが依存関係のキャッシュを使うと `postinstall` が動かず、Prisma Clientが作られないことがあったためです。
- 依存関係を更新しました（#62・#69）。Next.js は 16.3.8 から 16.4.1 になります。

**削除した環境変数**（使われなくなります。Vercelに残っていても害はありません）

`OPENAI_API_KEY`、`OPENAI_MODEL`、`CHAT_ENABLED`、`LINE_INTEGRATION_ENABLED`、`LINE_CHANNEL_SECRET`、`LINE_CHANNEL_ACCESS_TOKEN`、`LINE_BOT_USER_ID`、`LINE_ALLOWED_USER_ID`、`LINE_DRAIN_FORWARD_URL`、`CRON_SECRET`

**デプロイ前に必要な作業**

1. 保存済みのLINEのジョブとChatGPTの会話履歴を残したい場合は、先にバックアップを取ってください。
2. マイグレーション `20261020090000_drop_line_and_chat` を本番DB（Neon）に適用してください。**テーブル `LineLearningJob`・`LineDevelopmentSession`・`ChatConversation` を `DROP TABLE` するため、保存されていたデータは元に戻せません。** 今のコードはこの3テーブルを読み書きしないので、適用とデプロイの順番は問いません。手順はこれまでと同じです（`vercel env pull` → `migrate deploy` → `migrate status`）。

**デプロイ後に必要な作業**

1. LINE Developers で、Cloud Run向けのwebhookを止めてください。Vercelの `/api/line/webhook` はなくなったので、404になります。
2. 使わないなら、Vercelの上記の環境変数を削除してください（任意）。
3. Google Cloud側のCloud Runサービス、Secret Manager のシークレット、Cloud Tasks のキュー、Cloud Run用のGitHub OAuth Appは、コードを消しても残ります。使わないなら、それぞれの管理画面から削除してください（課金と秘密情報の放置を避けるため）。
