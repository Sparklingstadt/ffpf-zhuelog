# ロードマップ

学习録でこれから取り組むことを、「今」「次」「いつか」の 3 段に分けて並べます。済んだことは [リリースノート](releases/) にあります。

項目を始めたら「今」へ移し、リリースしたら消してリリースノートに書きます。項目は約束ではなく、順番も入れ替えてかまいません。

各項目の番号は、その項目を指すための ID です。段を移しても変えず、消した番号も使い回しません。新しい項目には、いちばん大きい番号の次を振ります。

## 方向

学習の中心は、自分で書いて添削された文（学習ノート）です。今のアプリは、それを「読む」「見返す」ことと、介詞・補語の文法を練習することができます。これからは次の 3 つを足していきます。

- **音**：読むだけでなく、聞いて確かめられるようにする。
- **自分の文の復習**：見返すだけのノートを、思い出す練習に回す。
- **間違いと練習のつながり**：自分がよく間違える点から、練習へ進めるようにする。

## いつか（Later）

### 5. 自分の間違いの傾向を見せ、練習へつなぐ

添削のヒント（例：「了の位置」）と、介詞・補語の練習の間違いを集計し、よく間違える点を一覧にします。介詞・補語の点なら、そのモードの練習へ進めるようにします。ヒントは自由に書いた文なので、同じ意味のヒントをどうまとめるかを先に決めます。

### 6. 練習の種類を増やす

介詞・補語に続く文法の練習を足します。候補は量詞、離合詞、把構文、了・过・着、是…的 などです。どれをどの出し方（4 択、並べ替えなど）で作るかは、まだ決めていません。例文のピンインと読み上げは、今の仕組みをそのまま使えるように作ります。

### 7. 学習ノートを検索・絞り込む

学習ノートは、日付と新しい順でしか探せません（`GET /v1/entries` に絞り込みがありません）。語句、添削か翻訳か、ヒントで探せるようにします。

### 8. 復習の期日を LINE で知らせる

LINE と連携しているメンバーに、期日が来た復習があるとき、1 日 1 回知らせます。Go API の LINE クライアントには送信（push）がすでにあり、Cron も動いています。LINE の無料メッセージ数の上限に収まるかを確かめ、通知を止める設定も用意します。

### 9. 例文から単語帳に入れる

単語帳には、学習ノートから語句を選んで入れられます。練習と復習の例文からも、同じように語句を選んで入れられるようにします。

### 10. 例文のピンインを隠しておく

練習と復習で、例文のピンインを最初は隠しておき、自分で読んでから出せるようにします（設定で切り替え）。
