# ロードマップ

学习録でこれから取り組むことを、「今」「次」「いつか」の 3 段に分けて並べます。済んだことは [リリースノート](releases/) にあります。

項目を始めたら「今」へ移し、リリースしたら消してリリースノートに書きます。項目は約束ではなく、順番も入れ替えてかまいません。

## これまで

- 学習ノート：添削前後の中国語・ピンイン・学習ヒントの記録、CSV の取り込み、日付別の学習ログ、ゴミ箱、フォローと共有
- 練習：介詞の練習、補語の練習（結果・可能・程度、方向補語の 4 モード、「動詞から選ぶ」）、間違えた問題の「今日の復習」
- アカウント：GitHub・ID とパスワード・FFPF ID でのログイン、ゲスト
- そのほか：単語帳、クイック質問、ChatGPT との会話練習、LINE 連携、Web と共通の Go API

## 今（Now）

### 練習で正解したとき、例文のピンインを出す

補語と介詞の練習で、正解したときに例文の上に文全体のピンインを出します。ピンインは pinyin-pro で生成し、多音字の誤読を直したうえで保存します（[PR #134](https://github.com/Sparklingstadt/ffpf-zhuelog/pull/134)）。

### 「今日の復習」でも例文とピンインを出す

「今日の復習」で補語・介詞の問題に正解したときも、練習の画面と同じように、和訳の上に例文と文全体のピンインを出します（[PR #134](https://github.com/Sparklingstadt/ffpf-zhuelog/pull/134)）。

## 次（Next）

いまはありません。始めるものを「いつか」から選んでここへ移します。

## いつか（Later）

### 練習の種類を増やす

介詞・補語に続く文法の練習を足します。候補は量詞、離合詞、把構文などです。どれをどの出し方（4 択、並べ替えなど）で作るかは、まだ決めていません。
