# ロードマップ

学习録でこれから取り組むことを、「今」「次」「いつか」の 3 段に分けて並べます。済んだことは [リリースノート](releases/) にあります。

項目を始めたら「今」へ移し、リリースしたら消してリリースノートに書きます。項目は約束ではなく、順番も入れ替えてかまいません。

各項目の番号は、その項目を指すための ID です。段を移しても変えず、消した番号も使い回しません。新しい項目には、いちばん大きい番号の次を振ります。

## 方向

学習の中心は、自分で書いて添削された文（学習ノート）です。今のアプリは、それを「読む」「見返す」「探す」ことと、介詞・補語・量詞の文法を練習することができます。足していくものは次の 3 つで、いまの進み具合は次のとおりです。

- **音**（済み）：読むだけでなく、聞いて確かめられるようにする。例文・学習ノート・単語を読み上げられます（v0.25.0）。
- **自分の文の復習**（済み）：見返すだけのノートを、思い出す練習に回す。学習ノートを「今日の復習」に入れられ、期日の来た朝には LINE でも知らせます（v0.25.0・v0.27.0）。
- **間違いと練習のつながり**（これから）：自分がよく間違える点から、練習へ進めるようにする。いつかの 5 です。

お金を払ってもらえるサービスにするまでの道筋は、別に [収益化までのロードマップ](monetization-roadmap.md) に書いています。そこで始めた項目も、ここに番号を振って「今」へ載せます。

### 15. 復習の答えに次の間隔を出し、キーで答えられるようにする

「もう一度・難しい・できた・簡単」に、次に出る時期（例：10 分後、4 日後）を添えます。スペースでめくり、1〜4 で答えられるようにします。

## いつか（Later）

### 16. 学習ノートの詳細で前後のノートに移れるようにする

その日の別のノートへ行くたびに一覧へ戻る必要があります。

### 17. AI が使えないときの案内を直す

会話のページに「Go API に OPENAI_API_KEY を設定すると」と開発者向けの文が出ます。クイック質問の案内と書き方もそろっていません。Web は AI が使えるかを知らないので、メニューから隠すには Go API の `GET /v1/me` などで知らせる必要があります。

### 18. 会話のページの幅をほかとそろえる

会話のページだけ左右いっぱいに広がり、見出しの位置がずれます。

### 5. 自分の間違いの傾向を見せ、練習へつなぐ

添削のヒント（例：「了の位置」）と、介詞・補語の練習の間違いを集計し、よく間違える点を一覧にします。介詞・補語の点なら、そのモードの練習へ進めるようにします。ヒントは自由に書いた文なので、同じ意味のヒントをどうまとめるかを先に決めます。

### 12. 練習の種類をさらに増やす

量詞（6、v0.27.0）と了・过・着（v0.31.0）に続けて、是…的、離合詞、把構文 などの練習を足します。ここまでの 2 つは 4 択で作り、記録は補語の記録と同じ表に `mode` を足して保存しました。是…的 と離合詞は、語順の違う文から正しいものを選ぶ 4 択にすれば同じ作りで足せます。把構文は並べ替えが向くので、4 択以外の出し方にするなら、記録と復習の形から考え直します。
